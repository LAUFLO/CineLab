# NODE-POLISH-1 · 音频波形、双击菜单、时间线、文本节点、拉片布局、分镜表间距

日期：2026-11-09

## 1. 音频波形

- 柱数 96 → 60，间距更疏。
- 波形区去掉外层 `padding: 6px 10px 8px`，改为铺满节点卡片；背景圆角由卡片 `overflow: hidden` 统一裁剪，不再出现上下/右侧白条。
- 播放按钮从 32px 带边框改为 28px 无边框，悬停显示底色。
- 控制条高度 34 → 36，左右 padding 12。
- 版本切换从右下角移到波形右上角，避免遮挡总时长。

## 2. 双击菜单

- 画布空白双击的「添加节点」菜单新增「剪辑室」，位于「添加资源」区域首位，点击创建并直接进入剪辑室。

## 3. 剪辑室时间线

- 视频/图片缩略图透明度 0.55/0.6 → 0.92/0.95。
- 音频波形透明度 0.5 → 0.8。
- 去掉视频片段上的青色渐变蒙层，改为淡色底，时间线不再灰蒙蒙。

## 4. 文本节点

- 双击不再打开编辑器，只聚焦/选中节点（内容区阻止双击冒泡，避免画布缩放）。
- 移除节点内右上角的「编辑」悬浮按钮。
- 编辑入口统一为：上方工具栏「编辑」、右键菜单「编辑文本」、工具栏「放大编辑」。
- 新增 UI store 全局 `textEditorNodeId / openTextEditor / closeTextEditor`，右键菜单可直接打开编辑器，不依赖节点工具栏。
- 长串自动换行：`overflow-wrap: anywhere` + `word-break: break-word`，`pre` 保持横向滚动。
- 滚动条改为 7px 透明轨道 + 52% 灰色圆角 thumb，悬停 72%；编辑器输入框与预览区同步。

## 5. 拉片节点

- 按钮统一 30px 高，与下拉框、chips 对齐。
- 「查看分镜表 / 重新拉片」放到底部右侧（`margin-top: auto` + `justify-content: flex-end`）。
- 下拉框 26 → 30，chips 24 → 28，卡片 gap 6 → 8、padding 10×12。

## 6. 分镜表浮窗

- 顶部间距 24 → 48，与剪辑室窗口一致；面板高度相应改为 `calc(100vh - 72px)`。

## 验证

- `corepack pnpm typecheck` 通过
- `corepack pnpm test`：24 文件 / 145 用例通过
- `corepack pnpm build` 通过
- 实测：音频波形 60 根、铺满圆角卡片；文本长串 `scrollWidth = clientWidth`，不再横向溢出；双击文本节点不弹编辑器；右键菜单出现「编辑文本」并可打开；双击菜单出现「剪辑室」；分镜表面板 top=48。
