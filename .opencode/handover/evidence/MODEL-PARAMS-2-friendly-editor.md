# 模型参数编辑器友好化验证

日期：2026-11-07
关联：`docs/model-params-plan.md`

## 问题

- 首次配置不知道参数怎么写
- 快速添加后仍是原始 key/字段名
- select 选项要求手写 `1024x1024|1024×1024`
- 数字参数没有 min/max 编辑入口

## 改动

- 常用参数从 chips 改为卡片网格：
  - 图片：尺寸、画面比例、数量、质量、随机种子
  - 视频：画面比例、时长、分辨率、生成音频、帧率
  - 音频：声音、语速、格式
  - 文本：温度、最大 token
  - 每张卡片带说明、默认值/选项数、「+ 添加」/「已添加」
  - 支持「全部添加」
- 参数行结构化编辑：
  - 显示名、控件类型、分组、接口字段名
  - select 选项逐行「显示名 / 接口值」编辑，可增删，默认选项下拉
  - number 支持默认值/最小值/最大值
  - text 支持默认文本
  - boolean 支持开启/关闭
- 保存前校验：显示名/字段名必填、字段名不重复、select 至少一个选项、数字默认值有效、min ≤ max

## 实测

- 打开测试图片模型 → 参数编辑器显示 5 张常用参数卡片
- 点击「全部添加」后生成 5 个参数、18 个选项
- 保存后设置页显示「5 个参数」
- 重新打开参数编辑器，5 个参数和选项均保留
