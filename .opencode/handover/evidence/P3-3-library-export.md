# P3-3 资产库与导出增强验证

日期：2026-11-07

## 批量选择

- 资产库 → 场景文件夹 → 选择模式
- 选中 2 个视频后底部显示：全选 / 清空 / 已选 2 个 / 移动到 / 合成视频 / 删除 / 完成
- 选中卡片显示勾选标记，合成视频按钮由禁用变为可用

## 视频合成

合成面板验证：

- 分辨率：720P / 1080P
- 画质：标准 / 高画质
- 提示：按资产列表顺序拼接 2 段视频，统一 H.264/AAC，输出 MP4

独立 ffmpeg 验证（与 `concat.ts` 相同参数）：

```json
{ "exists": true, "size": 1792863, "duration": 8.214, "hasAudio": true }
```

两段 4 秒视频成功拼接为 8.214 秒 MP4，包含音轨。
