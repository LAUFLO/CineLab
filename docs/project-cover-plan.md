# 项目封面方案

日期：2026-11-06
状态：已完成（2026-11-06）

## 目标

项目卡片支持更换封面图，来源：

1. 本地图片（文件选择对话框）
2. 当前画布中的图片节点

欢迎页和「全部项目」弹窗共用同一套卡片组件与封面比例（1:1）。

## 数据

- `ProjectMeta` 新增可选 `cover` 字段，固定指向项目根目录的 `cover.png`
- `RecentProject` 新增可选 `cover` 标记
- 读取最近项目时检查 `cover.png` 是否存在，存在则标记

## 存储

- 封面文件：`<project>.cinelab/cover.png`
- 统一中心裁切为 1:1，缩放 512×512，PNG
- 不修改项目 `updatedAt`，避免封面操作影响最近项目排序

## 主进程 IPC

| 方法 | 作用 |
|---|---|
| `project:cover-read` | 读取封面，返回 data URL 或 null |
| `project:cover-set-local` | 打开图片选择对话框，写入封面 |
| `project:cover-set-asset` | 从项目内图片资产写入封面 |
| `project:cover-remove` | 删除封面 |

路径安全：资产路径必须解析在项目目录内；本地选择仅允许图片扩展名。

## 渲染进程

- 新增 `ProjectCard` 组件，统一欢迎页与「全部项目」弹窗
  - 有封面显示图片，无封面显示文件夹占位
  - 悬浮显示「更换封面」按钮
  - 菜单：从本地选择 / 从画布选择（仅当前打开项目）/ 移除封面
- 新增画布图片选择弹窗
  - 列出当前画布中 `kind === 'image'` 的项目内资产
  - 缩略图按 1:1 展示
- 封面变更后刷新最近项目列表

## 兼容

- 无 `cover.png` 的旧项目保持文件夹占位
- 封面文件缺失时自动回退占位
- 图片读取失败不阻塞项目列表

## 验证

- `pnpm typecheck` / `pnpm build`
- dev 环境：本地图片、画布图片两种来源
- 欢迎页与全部项目弹窗封面比例一致（1:1）
- 深浅主题截图
