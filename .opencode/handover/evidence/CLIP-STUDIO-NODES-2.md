# CLIP-STUDIO 节点接线第二刀：上传同步、批量入口、删除与复制

日期：2026-11-07
状态：完成
验证：typecheck / 57 测试 / build 通过；CDP 端到端实测

## 1. 上传素材同步

- 「上传」页签与底部按钮接上真实上传按钮。
- 上传流程：
  1. `library.importAssets('剪辑室素材')` 选择本地文件
  2. `media.probe` 读取尺寸、时长、fps、hasAudio
  3. 按图片 / 视频 / 音频创建画布素材节点
  4. 自动成组「剪辑室素材 N」，放在剪辑室左侧
  5. 每个节点自动连到剪辑室
  6. 切换到「画布素材」页签即可看到
- 素材来自全局资产库，节点 `OutputRef.scope` 明确写 `global`，避免走项目路径加载失败。
- 节点标题使用资产名，不再全部叫「剪辑室素材 1」。
- 单文件上传也允许成组（`createGroupFromNodes` 新增 `allowSingle`）。

实测：上传 1 张图片 + 1 个视频：

| 项 | 结果 |
|---|---|
| 新节点 | 2 个 |
| 新分组 | 1 个「剪辑室素材 3」 |
| 连线 | 2 条，均指向剪辑室 |
| scope | 均为 `global` |
| 标题 | 图片名 / 视频名 |
| 画布素材页签 | 按入边顺序显示 3 个批量素材 + 2 个上传素材 |
| 缩略图 | 图片走 `cinelab-asset://global/...`，naturalWidth 1536 |

## 2. 多选 / 分镜组入口

- `createStudioFromNodes(nodeIds)`：
  - 支持媒体节点、成片节点、普通分组、分镜组
  - 分组自动展开子节点
  - 按选择顺序去重
  - 在包围盒右侧 80px 创建剪辑室
  - 依次建立 `素材 → 剪辑室` 连线
- 多选工具栏新增「剪辑室」。
- 分镜组工具栏新增「剪辑室」。
- 「画布素材」按入边顺序展示，保证顺序一致。

实测：

| 场景 | 结果 |
|---|---|
| 多选 3 个媒体节点 | 创建「剪辑室 2」，3 条入边，素材池顺序 1/2/3 |
| 分镜组 2 个图片 | 创建「分镜组 1 · 剪辑室」，2 条入边 |
| 成片节点作为素材 | 允许，和媒体节点一样连入新剪辑室 |

## 3. 删除语义

- 确认弹窗扩展为三按钮：取消 / 一起删除 / 保留成片。
- 剪辑室 + 成片：
  - **保留成片**：成片节点原地转成 `cine` 视频节点，保留全部 `outputs`、标题、位置和下游连线；剪辑室删除。
  - **一起删除**：剪辑室和成片一起删除。
- 单独删除成片：
  - 清空剪辑室 `filmNodeId`
  - 徽章显示「成片缺失」
  - 下次打开/保存剪辑室自动补建成片节点
- 删除分组沿用组内子节点一起删除。
- 键盘 Delete / Backspace 与多选删除按钮统一走 `requestDeleteSelection()`。

实测：

| 场景 | 结果 |
|---|---|
| 保留成片 | 剪辑室消失；成片变为 `cine` / `video`；outputs 1 个保留；`成片 → 下游节点` 连线仍在 |
| 一起删除 | 剪辑室与成片均消失 |
| 单独删成片 | film 数 0；徽章「成片缺失」；重新打开剪辑室后自动生成新 film，状态 `pending` |
| 确认弹窗 | 标题「删除剪辑室」，按钮「取消 / 一起删除 / 保留成片」 |

## 4. 复制与粘贴

- 新增 `timeline:duplicate(sourceId)`：
  - 读取源时间线文件
  - 生成新 id
  - 文档名加「副本」
  - 原子写入新文件
- 多选「创建副本」：
  - 选中剪辑室时先深拷贝时间线
  - 新剪辑室替换 `timelineId`
  - 清空 `filmNodeId`，不复制成片
  - 标题加「副本」
- `Ctrl+C / Ctrl+V`：
  - 复制含剪辑室的选择时，粘贴阶段先生成新时间线文件
  - 粘贴的剪辑室使用新 id
  - 内部连线按新节点 id 重建；引用了未复制节点的边会被丢弃
- 成片节点不参与复制。

实测：

| 场景 | 结果 |
|---|---|
| 创建副本 | 新 `timeline_e8738ca4-...json`（1516B）；新剪辑室 title「剪辑室 2 副本」；film 数仍为 1；原时间线文件不变 |
| Ctrl+C / Ctrl+V | 新 `timeline_61af1ff1-...json`（1516B）；新剪辑室新 id；film 数仍为 1 |
| 副本内容 | 与原时间线同为 1 个片段，编辑互不影响 |

## 5. 持久化

页面 reload 后：

- 3 个剪辑室（原 / 副本 / 粘贴副本）保留
- 1 个成片保留
- 3 个分组保留
- 7 条连线保留
- 时间线文件全部存在

## 6. 已知缺口（第三刀）

- 上游素材节点产生新版本时，素材池「有新版本」提示与成片 `stale` 联动。
- 时间线片段引用的素材被删除时标记 `missing`。
- 无输出媒体节点目前没有节点工具栏，因此没有剪辑室入口。
- 工具栏宽度未在 360 / 480 节点上实测。
- 分组内嵌套剪辑室/成片的删除与复制边界未覆盖。
- 上传文件进入全局库「剪辑室素材」文件夹，不复制到项目 `assets/`。
- 上传对话框本身无法用 CDP 自动操作；本轮验证的是选择文件之后的建节点/成组/连线逻辑，对话框使用 Electron 标准 `showOpenDialog`。
