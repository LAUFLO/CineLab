# CLIP-STUDIO P3：字幕编辑、烧录、VTT 与节点收尾

日期：2026-11-08
状态：完成
验证：typecheck / 57 测试 / build 通过；CDP 端到端实测

## 1. 字幕添加

- 时间线工具栏新增「字幕」按钮。
- 在播放头创建 3 秒文字片段：
  - 自动找字幕轨；没有则创建「字幕 1」
  - 默认内容「新字幕」
  - 字号 64、白色、居中、粗体/斜体关闭
  - 黑色描边 2px + 阴影
- 创建后自动选中，属性面板直接进入字幕编辑。
- 时间线片段标签显示字幕内容，不再只显示名称。

## 2. 字幕编辑

属性面板「字幕」区：

- 内容 textarea（失焦 / Ctrl+Enter 保存）
- 字体
- 字号
- 颜色
- 对齐
- 粗体 / 斜体
- 阴影开关
- 描边宽度

- 使用 `updateClip` 写入 `clip.text`，同时同步 `clip.name` 为内容前 60 字。
- 样式提交使用 ref 保存最新值，避免快速连续修改互相覆盖。
- 预览使用同一 `drawText` 渲染器，改完立即反映在画布预览。

## 3. 烧录实测

时间线：1 张图片 5 秒 + 1 条字幕 0-3 秒。

- 预览 canvas 截图：图片上显示「你好 CineLab」，黄色、粗体、居中。
- 导出 MP4：1920×1080 / 5.000 秒 / 150 帧 / 161KB。
- 用 ffmpeg 抽 1 秒帧：字幕已烧录进视频画面。

## 4. VTT 导出

- 成片节点新增「VTT」按钮。
- 导出前保存/加载当前时间线。
- 过滤条件：
  - 片段 kind 为 text
  - 位于 subtitle 轨
  - 轨道 visible 且未 muted
  - 片段未 muted
  - 内容非空
- 按 startMs 排序，输出标准 WebVTT。
- 文件写入 `exports/字幕-<时间>.vtt`。

实测文件内容：

```vtt
WEBVTT

00:00:00.000 --> 00:00:03.000
你好 CineLab
```

无字幕时主进程抛出「时间线没有可导出的字幕」，UI toast 显示。

## 5. 节点收尾

### 批量存在性

- 新增 `media:exists-many(entries)`，一次返回多个路径。
- `analyzeClipReferences` 先收集唯一 `scope:path`，再批量查询。
- 实测：`[true, false, false]`，与单条查询一致。

### 工具栏图标化

- 「下载 / 展开 / 入库」改为纯图标按钮，保留 title / aria-label。
- 「剪辑室」保持文字按钮。
- 仍保持 6 个主操作上限和 36px 高度。

实测（视口 1240）：

| 节点 | 图标化前 | 图标化后 |
|---|---|---|
| 360px 图片 | 471×36 | 378×36 |
| 480px 视频 | 735×36 | 642×36 |

视频工具栏仍宽于节点，但按屏幕位置右对齐后完整可见。

### 多时间线

- 每个剪辑室节点都有独立 `timelines/<id>.json`，多个剪辑室节点即多条独立时间线。
- 「单个剪辑室内切换多条时间线」方案文档没有定义，本轮不做。

## 6. 持久化

页面 reload 后：

- 字幕片段仍在字幕轨
- 内容「你好 CineLab」、字号 96、颜色 #ffcc00、粗体保留
- 时间线片段标签仍显示字幕内容
- 成片版本与 VTT 文件不受影响

## 7. 已知限制

- 不支持导入 SRT / VTT。
- 自动字幕（whisper）属于 P4，尚未接入。
- VTT 只导出 subtitle 轨上的文字；视频轨文字作为画面标题，不进入 VTT。
- 多语言字幕轨未定义语言字段。
- 字幕重叠时不会自动截短前一条，允许重叠。
- 颜色选择器拖动可能产生多条撤销记录。
- 单个剪辑室内多时间线未定义。
