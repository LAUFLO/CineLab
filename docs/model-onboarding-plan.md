# 模型配置引导方案（P1-1）

日期：2026-11-07
状态：实施中
关联：`docs/roadmap-plan.md` P1-1

## 现状

- 设置页可以手动添加供应商（名称、类型、Base URL、Key、模型），已有「测试连接」和「获取模型列表」
- 欢迎页和画布没有空配置引导；新用户只会在 prompt bar 看到「未配置模型」
- 添加供应商是空白表单，常见 Provider 需要用户自己查地址和模型 ID
- 测试连接失败时直接展示 `String(error)` 或原始 HTTP 文本，缺少可操作提示

## 目标

全新用户数据目录下，从欢迎页可以：

1. 看到「配置模型」入口
2. 在设置页一键选择常见 Provider 预设
3. 填 Key 后测试连接，得到明确结果
4. 保存后回到画布，能开始第一次生成

## 设计

### 1. Provider 预设

新增 `src/shared/provider-presets.ts`：

- 预设字段：`id`、`name`、`description`、`type`、`baseUrl`、`models`
- 覆盖：OpenAI 兼容、MOSS、智谱、Vidu、MiniMax、可灵、火山方舟、Agnes
- 只预填元数据，不预填 Key；模型引用 `MODEL_PRESETS` 或内置自定义模型
- 用户仍可修改地址和模型

### 2. 设置页

- 供应商列表下方增加「快速预设」按钮组，点击直接进入已预填的表单
- 保留「+ 添加供应商」空白入口
- 保存成功后，如果此前没有任何供应商，toast「模型配置完成，回到画布开始创作」

### 3. 欢迎页入口

- `ProjectCenter` 挂载时加载 providers
- 没有「可用配置」（无供应商、无模型或无 Key）时，在欢迎卡片下方显示配置提示条：
  - 标题：还没有配置模型
  - 说明：添加一个模型供应商后即可开始生成
  - 按钮：配置模型 → `openPanel('models')`

### 4. 画布入口

- `PromptBar` 的「未配置模型」按钮改为打开设置并定位「模型服务」

### 5. 测试连接错误文案

在 `testConnection` / `fetchModels` 统一分类：

| 情况 | 文案 |
|---|---|
| 超时（15/20 秒） | 连接超时，请检查 Base URL 或网络 |
| DNS 失败 | 域名解析失败，请检查 Base URL |
| 连接拒绝 | 连接被拒绝，请检查 Base URL 和端口 |
| 连接重置 | 连接被重置，请稍后重试 |
| HTTP 401/403 | API Key 无效或没有权限 |
| HTTP 404 | 接口不存在，请检查 Base URL 版本路径 |
| HTTP 5xx | 服务端错误，请稍后重试 |
| 其他 | 原始错误信息 |

## 验收

- 全新 userData 下欢迎页出现配置入口
- 选择预设后表单名称、类型、Base URL、模型已预填
- 用 `scripts/mock-openai.mjs` 测试连接成功，并返回模型列表
- 错误 Base URL / 错误 Key 给出可操作提示
- 保存首个供应商后出现成功提示，回到画布可正常选择模型
