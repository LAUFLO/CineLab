# 画布操作基础

## 适用场景

用户要求查看画布、修改节点标题或移动节点时使用。

## 步骤

1. 先调用 `canvas_get`，确认当前画布和选中节点。
2. 只修改 `canvas_get` 返回的 `selectedNodes` 中的节点。
3. 修改标题使用 `canvas_update_title`，移动节点使用 `canvas_move_node`。
4. 不要编造节点 ID、画布 ID 或坐标。
5. 操作完成后用一句话说明实际改了什么。

## 约束

- 只读模式下不能修改画布。
- 只允许修改当前选中的节点。
- 一次自然语言请求可以包含多个操作，但都必须在同一轮内完成。
- 不删除节点、不创建节点，除非用户明确要求且工具已开放。
