| 分区 | 现有内容 | 问题 |
|---|---|---|
| 模型服务 | 供应商、模型、参数、连接测试 | 完整，保持独立 |

当前常规偏好分散在四处：

- 主题：`localStorage` + `app:set-theme`
- 生成历史：`localStorage`，固定保留 50 条
- 画布吸附 / 小地图 / 连线：内存 Zustand，重启丢失
- 自动保存：固定 600ms 防抖；生成并发固定 2；启动固定打开最近项目

## 2. 同类产品参考

- **剪映全局设置**：草稿位置、素材下载位置、缓存管理（自动删除天数）、草稿自动备份、默认保存位置
- **Figma**：语言、界面缩放、桌面通知、自动保存
- **ComfyUI**：画布背景/网格、连线样式、节点透明度/字号、组内边距、节点搜索、开发模式
- **AI 画布类工具（LibTV / 即梦 / 可灵）**：默认模型、生成完成通知、自动保存、节点吸附、界面密度

共性结论：通用设置通常覆盖「启动与项目、画布交互、生成行为、通知、存储与缓存、界面、高级」七类。

## 5. 存储方案

现状问题：偏好分散，主进程启动逻辑读不到渲染进程的设置。

实施方式：

- 主进程新增 `preferences.json`（`userData` 下），逐字段校验 + 默认值合并
- IPC：`settings:get-preferences` / `settings:save-preferences` / `settings:reset-preferences` / `settings:open-data-dir`
- 渲染进程新增 `preferencesStore`，启动时加载
- 主进程启动逻辑（打开最近项目、生成并发）直接读 preferences
- 画布吸附 / 小地图改为持久化偏好，底栏切换时同步写回
- 主题仍由现有「外观」分区管理（localStorage），不并入通用

偏好字段：

```ts
{
  startup: { openRecentProject: boolean }
  project: { autoSaveDelay: number }
  canvas: { snapToGrid: boolean; minimapVisible: boolean; reduceMotion: boolean }
  generation: {
    defaultModels: { image: string | null; video: string | null; text: string | null; audio: string | null }
    concurrency: number
    notifyOnComplete: boolean
    autoLink: boolean
    historyLimit: number
  }
}
```

## 6. 不建议放入通用设置

- 模型服务、操作模型、组件、资产库路径、软件更新、关于：保持独立 tab
- 快捷键自定义：后续独立 tab
- 云同步、账号、遥测：当前没有对应能力
- 语言：等引入 i18n 后再做

## 7. 建议的 UI 结构

```
设置
├─ 通用
│  ├─ 启动与项目
│  ├─ 画布与交互
│  ├─ 生成与提示词
│  ├─ 通知与更新
│  ├─ 存储与数据
│  ├─ 界面（缩放）
│  ├─ 网络与请求
│  └─ 高级（备份、重置）
├─ 模型服务
├─ 操作模型
├─ 资产库
├─ 组件
├─ 外观（主题，后续扩展连线颜色）
├─ 快捷键
└─ 关于
```

每个设置项采用「标题 + 一行说明 + 右侧控件」结构，复用现有 `.settings-section` / `.settings-group-title` / `.settings-hint` 样式。

## 8. 实施顺序

- P1：MVP 第 1–11 项 + preferences 存储（已完成）
- P2：默认项目目录、关闭前确认、滚轮行为、双击缩放、网格样式、显示连线、界面缩放、缓存清理、代理、超时（已完成）
- P3：更新通道、导入/导出设置、失败自动重试、默认水印、通知与更新开关（已完成）
- 暂缓：语言（需要全量 i18n）、快捷键自定义（独立 tab）

## 9. 验收

- 修改设置后重启应用仍保留
- 关闭「启动打开最近项目」后，启动进入项目中心
- 底栏吸附/小地图/连线开关与通用设置双向同步
- 默认模型在切换节点、重开项目后仍生效
- 生成并发数修改后主进程队列立即生效
- 生成完成且窗口未聚焦时收到系统通知
- 重置设置后恢复默认值并提示确认
