# NODE-TOOLBAR P2 交互增强验证记录

- 日期：2026-11-05
- 范围：自由裁剪、框选去字幕、3D 光位球 / 方位球

## 实现

- `useBoxEditor.ts`：通用选框拖拽 + 四角缩放 hook。
- `CropDialog.tsx`：图片自由裁剪，按原图坐标换算。
- `SubtitleDialog.tsx`：视频字幕区域框选。
- `SphereDialog.tsx`：3D 光位 / 机位球，拖拽更新方位与俯仰；打光附加亮度 / 色温，机位附加景别。
- `node-operations.ts`：自由裁剪、框选去字幕、自定义光位 / 机位入口。
- `image.ts` / `video.ts`：`cropImageRect`、`removeSubtitles`。
- `media` IPC / preload / contract 扩展。

## 验证

1. `typecheck` / `build` 通过。
2. 自由裁剪：CropDialog 打开，stage 420×420，初始框 819×819；应用后新增 819×819 版本，节点高度 642。

6. 测试版本与资产已清理，测试窗口保持运行。

## 限制

- delogo 对复杂背景效果有限。
- 球体为 2D 投影交互，不是真 3D 场景。
- 打光 / 机位提示词仍是文本约束，效果取决于模型。
