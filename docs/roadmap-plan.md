# CineLab 后续路线图

日期：2026-11-11
状态：现行
适用版本：`main` @ `b76a064`

## 1. 当前状态

- 无限画布、多项目 / 多画布、资产库、分组/分镜、节点工具栏、生成队列、导出均已完成。
- 剪辑室、导演台、逐帧拉片已进入 main。
- CineBot Phase 1–4 已完成：画布、剪辑、导演台、拉片工具，节点操作桥，能力目录，生成提案。
- 当前注册 56 个 Agent 工具；单元测试 42 个文件、312 个用例。
- GitHub Actions `Build Windows` 已跑通：typecheck、test、check:encryption、build、electron-builder、artifact 上传。
- 版本仍为 `0.1.0`，尚未做代码签名和正式发布。

## 2. 已完成（2026-11-11 基线）

### 画布与生成

- 无限画布、节点连线、自动保存、崩溃恢复
- 多项目 / 多画布、项目中心、项目封面
- OpenAI 兼容文生图 / 图生图 / 文本 / TTS
- 可灵、火山方舟、MiniMax、Vidu 视频适配器
- 分组节点、分镜组、2K 拼接、版本栈
- 节点工具栏：九宫格、多角度、打光、人像、抠图、自由裁剪、3D 光位
- 深度动作捕捉（VDA Small，组件按需下载）

### 剪辑室

- 多轨时间线：视频、音频、字幕、图片
- 片段裁剪、切分、移动、吸附、速度、音量、透明度、淡入淡出、转场
- 自动字幕、删静音、按镜头切分、节拍标记、节拍切分
- ffmpeg 导出并写回画布成片节点

### 导演台

- three.js 3D 视口、人物素模、基础几何体、群众、glTF
- 多机位、机位关键帧运镜、镜头时长/画幅
- 对象姿势/颜色/可见性、背景
- 白模预演导出并回到画布

### 逐帧拉片

- 视频节点 → 拉片节点 → 分镜组/分镜表
- 镜头检测或固定间隔拆分，AI 描述景别/机位/运镜/光线/画面/提示词
- 段落编辑、内嵌字幕提取、Markdown / AI 分析包 / 拉片包导出
- 原拉片室保留为分镜表「高级编辑」

### CineBot

- 自研 AgentRuntime、SSE 流式、工具调用、会话 JSONL、上下文压缩
- 权限模式、确认卡、回合撤销、技能三级目录
- 画布 / 剪辑 / 导演台 / 拉片工具
- 节点操作桥：UI 和 Agent 共用 runner
- 能力目录与 `capability_search`
- 生成提案：operationId / itemId / mask，确认后提交

### 工程

- Vitest 单元测试
- GitHub Actions Windows 打包与 artifact
- `check:encryption`、CDP 隔离实例脚本、Agent fake eval 基础
- 自动更新、日志、错误反馈基础

## 3. P0：发布前

### P0-1 安装包瘦身

现状：`ffprobe-static` 带全平台二进制，安装包约 157MB，zip 约 200MB。

动作：

- electron-builder `files` / `asarUnpack` 只保留 win32 x64 ffprobe
- 检查 ffmpeg-static 是否同样带多平台二进制
- 对比瘦身前后安装包，验证打包态 probe、剪辑导出、深度捕捉

验收：

- 安装包下降 60–80MB
- 打包态媒体功能正常

### P0-2 正式发布流程

- 代码签名证书 / 发布渠道确认
- 自动更新正式启用
- GitHub Release 自动上传安装包和 latest.yml
- 版本号与 CHANGELOG 规范

### P0-3 真实素材复测

- 深度动作捕捉：横屏、竖屏、大运动、低照度各一段
- 拉片：长视频、连续舞蹈、无镜头切换素材
- 剪辑导出：多轨、字幕、转场、BGM

## 4. P1：CineBot 剩余能力

### P1-1 蒙版类节点操作

`inpaint` / `erase` / `element-edit` 仍需要界面涂抹。可选方向：

- Agent 接收项目内 mask 图片路径
- 提供简单矩形/画笔 mask 参数
- 与 `generation_propose` 的 mask 字段打通

### P1-2 拉片分析包导入

- Agent 按项目内路径导入 JSON 分析结果
- 校验 schema、版本和段落边界
- 写入 study 快照并支持回合撤销

### P1-3 导演台动作轨与灯光

- 对象动作轨（位置/旋转/姿势关键帧）
- 独立灯光实体或环境光参数
- Agent 工具补齐对应命令

### P1-4 真实 tokenizer 与动态工具暴露

- 按模型 contextWindow 估算 token
- 工具超过阈值时按 profile/空间分组暴露
- `capability_search` 与动态工具列表联动
- 工具结果裁剪与上下文预算

### P1-5 Agnes 视频补测

- `agnes-video-2.5-flash` 队列恢复后跑真实文生视频 / 图生视频
- 记录 503 `video_queue_full` 的退避和错误提示

## 5. P2：工程质量

### P2-1 文档防漂移

- 新增 `pnpm check:docs`
- 校验文档状态/日期、相对链接、README 文档索引
- 从 `AGENT_TOOLS` 生成 Agent 能力表，避免工具数量过期

### P2-2 Agent 回归场景

- 确认卡：删除片段/对象、切分、导出、拉片提取字幕
- 长任务：自动字幕、删静音、白模预演、逐帧拉片
- 取消与超时：工具执行中取消、60 秒确认超时
- 生成提案：未确认不提交、重复提交幂等

### P2-3 打包安装验证

- 干净 Windows 机器安装
- 首次启动、模型配置、组件下载、项目打开、导出
- 安装包升级/卸载

## 6. P3：功能候选

- 超分：图片/视频 2x/4x，本地模型或 API
- 外部 Agent / MCP / CLI 接入
- 多人协作（当前不做）
- 更多视频供应商和模板

## 7. 暂不做

- SQLite / 原生数据库
- 多人实时协作
- 在未完成代码签名前默认启用自动更新
- 把拉片恢复为独立工作台主入口
