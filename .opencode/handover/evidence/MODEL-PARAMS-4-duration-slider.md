# 视频时长滑条验证

日期：2026-11-07
关联：`docs/model-params-plan.md`、`MODEL-PARAMS-3`

## 需求

- 视频模型只支持部分固定时长（如 4/5/8/10s）时，保留下拉档位
- 支持连续秒数（如 4–12s）时，模型配置只填最小值/最大值
- Prompt Bar 用滑条选择范围内任意一秒

## 实现

- 模型参数编辑器对 `key === 'duration'` 的下拉参数显示「改为时长滑条」
- 点击后：
  - 读取现有选项的数值
  - 自动取 min/max
  - 切换为数字参数，保留/修正默认值
- Prompt Bar 已有 `duration` 数字参数滑块逻辑，1 秒步进
- 只支持固定档位的模型可继续使用下拉，不强制转换

## 实测

- 测试视频模型 duration 下拉：4/5/12
- 参数编辑器出现「改为时长滑条」
- 点击后控件类型变为「数字」
- 默认值 5、最小值 4、最大值 12
- 选项列表消失，时长提示消失
- Prompt Bar 的 `duration` 数字参数会渲染为 4–12 秒滑块

## 结论

时长是否连续由模型能力决定，不统一强制：

- 固定档位模型：下拉
- 连续秒数模型：数字 min/max + Prompt Bar 滑条
