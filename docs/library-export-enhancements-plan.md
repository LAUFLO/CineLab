# 资产库与导出增强方案（P3-3）

日期：2026-11-07
状态：已完成（含多轨音轨、资产标签）

## 已完成

### 1. 资产库多选与批量操作

- 资产库工具栏新增「选择」模式
- 卡片左上角勾选，支持全选、清空
- 批量「移动到」文件夹（复用现有文件夹树）
- 批量删除（应用内确认）
- 切换到其他文件夹时自动退出选择

### 2. 视频合成导出

- 选中 2 个及以上视频时可「合成视频」
- 合成面板提供导出预设：
  - 分辨率：720P / 1080P
  - 画质：标准（CRF 23）/ 高画质（CRF 18）
- 可选字幕：选择 SRT/ASS/VTT，烧录进画面（微软雅黑 + 描边）
- 可选背景音乐：选择音频后循环并混入原声
- 可选旁白：选择音频后混入
- 三路独立音量：原声 / BGM / 旁白（0–100%）
- 按资产列表顺序拼接，统一 H.264 + AAC，输出 MP4
- 主进程 `src/main/media/concat.ts`：
  - 每个片段先统一分辨率、帧率（30fps）、SAR、编码
  - 无音频片段自动补静音轨
  - concat demuxer 无损拼接，`+faststart`
  - 多轨混音：三路 `volume` → `amix=inputs=N:duration=first:normalize=0`
- IPC `export:concat-videos`，保存位置由系统对话框选择

### 3. 资产标签

- 资产卡片显示标签 chips，最多 3 个
- 操作按钮「编辑标签」，逗号分隔输入
- 标签存储在库根 `.tags.json`，不修改原文件
- 搜索框同时匹配文件名和标签
- 移动/删除/删除文件夹时同步维护标签记录
