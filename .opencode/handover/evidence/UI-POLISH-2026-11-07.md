# UI-POLISH-2026-11-07 · 验证记录

日期：2026-11-07
范围：节点尺寸、自动成组、对齐、视频预览、窗口和工具栏

## 已实现

- 图片节点默认宽度 614 → 360
- 视频节点默认宽度 614 → 480
- 宫格切分节点宽度 480 → 240（`GRID_SPLIT_CELL_WIDTH`）
- 分镜组保持 480；文本/音频保持 348/220
- 旧项目加载时把宽度 614 的图片/视频节点迁移到新尺寸，并按输出比例重算高度
- 宫格切分自动创建「宫格组 N」，按切分行列排列
- 分离音视频自动创建「音视频组 N」
- 多文件上传（≥2）自动创建「素材组 N」
- 对齐线只比较同侧边和中心线：左/右/水平中心、上/下/垂直中心
- 视频节点「展开」打开全屏视频浮窗，支持控件、背景点击关闭、Esc
- 图片预览改用 `assetUrl`，支持全局资产
- 首次窗口按工作区 86% 自适应，最大 1440×900，居中
- 节点工具栏固定 40px、反向缩放，按钮间距收紧
- 节点工具栏菜单恢复向下弹出

## 验证

- `typecheck` 通过
- `build` 和 `electron-builder --win --publish never` 通过
- 开发实例验证旧节点迁移：
  - 1:1 图片 614 → 360×388
  - 16:9 视频 614 → 480×298
- 宫格 2×2 验证：节点 240×268，组 552×620
- 宫格 3×3 理论：每格按自身比例计算高度，组按行高计算
- 宫格预览改为 `object-fit: contain`，避免卡片比例不一致时裁掉图片
- 宫格切分文件实测：2×2 四张 512×512 是原图精确四宫格，拼回原图 PSNR = inf
