# 音频节点真实波形

日期：2026-11-08
关联：`AUDIO-WAVEFORM-1`

## 问题

音频节点显示的是一段固定正弦图案，不是根据音频内容生成的波形。原实现虽然尝试用 Web Audio 解码，但失败时会退回固定图案，且自定义协议/编码格式可能导致解析失败。

## 实现

- 新增主进程 `media:audio-peaks`：
  - 使用 ffmpeg 解码为 4kHz 单声道 PCM
  - 按 96 个桶计算每个区间的峰值
  - 归一化并做平方根压缩，让小声段也可见
  - 按文件路径 + mtime + size 缓存结果
- 渲染进程 `AudioPlayer`：
  - 优先调用主进程获取真实峰值
  - 主进程失败时退回 Web Audio 解码
  - 两者都失败时显示平线，不再伪造正弦波形
  - 渲染时把峰值映射为 SVG 柱高
- 音频节点把 `path` / `scope` 传给播放器，支持项目内和全局资产库音频

## 实测

使用 4 秒测试 WAV：

- 0–0.8s：低音量
- 0.8–1.6s：高音量
- 1.6–2.4s：静音
- 2.4–4s：音量起伏

节点渲染 96 根柱，高度呈现真实结构：

```text
低音量段：27.4
高音量段：92.0
静音段：6.0
起伏段：59.8 → 75.1 → 31.5 → 75.1
```
