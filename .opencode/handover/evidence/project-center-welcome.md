# 项目中心与欢迎页验证

- 日期：2026-11-05
- 方式：CDP 清空/恢复 `recent-projects.json` + 页面刷新 + DOM 核对

## 行为约定

```
启动
 ├─ 有可打开的最近项目 → 直接进画布
 └─ 无可打开项目 → 项目中心（不可关闭的启动页）

删除当前项目
 ├─ 还有其他最近项目 → 自动打开最近的一个
 └─ 没有其他项目 → 项目中心空状态
```

`bootstrap()` 不再自动创建「未命名项目」，没有可打开项目时返回 `null`。

## 验证结果

| 项 | 结果 |
|---|---|
| 最近项目为空 | 通过，进入 `welcome` 状态 |
| 项目中心渲染 | 通过，`.welcome-screen` / `.project-center` 存在 |
| 主操作 | 通过，「新建项目」主按钮 |
| 次操作 | 通过，「打开已有项目」 |
| 空状态文案 | 通过，提示新建或打开 `.cinelab` |
| 画布是否渲染 | 通过，欢迎页不渲染 React Flow |
| 恢复最近项目 | 通过，刷新后回到画布，项目名/画布名正确 |

## 实现要点

- `bootstrap()` 返回 `ProjectSnapshot | null`，移除自动创建 fallback
- `project` store 新增 `welcome` phase
- `App.tsx` 在 welcome 渲染 `ProjectCenter`
- `ProjectCenter` 读取最近项目，提供新建、打开、最近项目网格
- `deleteProject` 删除后重新 `bootstrap`：有剩余项目则打开，没有则欢迎页
- 删除确认框文案已说明「将打开其他最近项目，或回到项目中心」
