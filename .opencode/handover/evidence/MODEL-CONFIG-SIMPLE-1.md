# MODEL-CONFIG-SIMPLE-1 · 模型参数配置简化与快速预设调整

日期：2026-11-09

## 1. 快速预设调整

- 移除「智谱 CogVideoX」：不是当前生图/生视频第一梯队。
- 火山方舟增加 **Seedream 5.0** 图片模型（OpenAI 兼容 `/images/generations`），描述改为「Seedance 视频 · Seedream 图片」。
- OpenAI 预设的图片模型从已停用的 GPT Image 1 更新为 **GPT Image 2.5**（`gpt-image-2.5`）。
- 保留 MOSS、Vidu、MiniMax、可灵、Agnes、OpenAI 兼容。
- **暂未添加 Google Gemini**：Gemini 的 OpenAI 兼容层只覆盖 chat，图片/视频需要专用适配器（`generateContent` + inlineData），放预设会变成「点了不能生成」，留到后续单独接。

## 2. 参数界面简化

### 术语

| 原来 | 现在 | 提示 |
|---|---|---|
| 下拉选择 | **选项** | 从预设值里选，例如比例 16:9 |
| 数字 | **数值** | 输入或拖动一个数，例如时长 5 秒 |
| 文本 | **文本** | 自由输入文字 |
| 开关 | **开关** | 开 / 关 |

参数卡片展开后会显示对应的类型提示，不再只看到一个术语。

### 默认折叠

- 参数列表默认全部折叠，每行显示：展开箭头、参数名、类型标签、当前默认值、删除按钮。
- 点行展开后才显示完整表单（显示名、类型、分组、可选项、高级字段名）。
- 新增参数时自动展开新行。
- 「高级：接口字段名」保持默认折叠。

### 模型行摘要

模型列表从「3 个参数」改为直接列出参数名：

```
文生图 · 输入 文本/图片 · gpt-image-2.5 · 参数 尺寸 · 画质 · 数量
```

超过 3 个显示「等」。

## 3. 时长统一滑条

- 所有内置模型预设的 `duration` 从固定秒数下拉改为 `number`（Prompt Bar 显示滑条）。
- 打开参数对话框时，旧的 `duration + select` 配置会自动迁移成数值范围：`min/max` 取原选项的最小/最大值，默认值保留。
- 覆盖 Seedance、Vidu、MiniMax H3、Hailuo、可灵、Agnes 等全部视频预设。
- 参数编辑器里「改为时长滑条」的提示保留，作为手动改回下拉后的补救入口。
