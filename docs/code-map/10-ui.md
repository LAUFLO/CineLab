# 10 UI 组件与面板

日期：2026-11-19
状态：现行
适用版本：v0.3.0
最后核对：2026-11-19

## 这个模块负责什么

通用 UI 组件库、设置/素材库等面板、主题与样式、应用入口。

## 不负责什么

- 不拥有业务逻辑；画布、剪辑、导演台的业务在各模块。
- 不直接访问文件系统或模型 API；这些走主进程 IPC（见 07）。

## 组件库

`src/renderer/src/components/ui/`：

| 组件 | 用途 |
|---|---|
| `Button`、`IconButton` | 按钮 |
| `Input`、`Select`、`NativeSelect` | 输入与下拉 |
| `Menu`、`Popover`、`Dialog` | 菜单与浮层 |
| `Field` | 表单字段 |
| `Switch` | 开关 |
| `Toast` | 轻提示 |
| `cn` | className 合并 |

约定（AGENTS.md）：

- 新增 UI 前先查 `components/ui/index.ts`；
- 下拉用 `Select`/`NativeSelect`，菜单/浮层用 `Menu`/`Popover`/`Dialog`，按钮/输入用 `Button`/`Input`/`Textarea`；
- 禁止业务代码自建浮层或原生控件；
- 提交前运行 `corepack pnpm check:ui`。

## 面板

`src/renderer/src/panels/`：设置、素材库、组件、确认框等用户可见面板。面板只负责展示与交互，数据通过 store 与 IPC 获取。

## 主题与样式

- `src/renderer/src/styles/tokens.css`：CSS 变量，主题颜色唯一来源；
- `src/renderer/src/theme/`：主题切换；
- 组件内禁止硬编码色值。

## 入口

- `src/renderer/src/App.tsx`：路由/空间切换；
- `src/renderer/src/main.tsx`：渲染进程入口；
- `src/renderer/src/env.d.ts`：环境类型声明。

## 数据流

```
App / panels
  → components/ui
  → store（canvas/timeline/stage/agent...）
  → preload CineApi
  → main IPC
```

## 已知限制

- 组件库变更影响全 UI，改 `Button`/`Dialog`/`Popover` 前先搜索调用点。
- 业务代码仍可能存在少量历史原生控件；`check:ui` 会列出问题。
- 面板与业务 store 的耦合需要逐面板确认，避免把业务逻辑写进面板。
