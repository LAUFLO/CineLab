# UI 交互打磨：节点比例、工具栏、智能引用、水印

## 范围

本轮会话在 M6 收尾后继续打磨节点与 prompt bar 交互。

## 完成项

| 项 | 说明 |
|---|---|
| 输出比例 | `GeneratedAsset` 记录图片真实宽高；视频按 `ratio` 推断尺寸；节点按输出比例调整高度 |
| 节点工具栏 | 由节点选中状态驱动，与 prompt bar 同时出现；主题配色；尺寸 42px |
| 图片浮窗 | 工具栏「展开」打开 portal 浮窗，点击遮罩或 Esc 关闭 |
| 比例网格 | `size` / `ratio` 参数改为 3 列网格，带比例图标 |
| 智能引用 | 默认开启，移入「高级设置」面板，匹配节点标题、素材名、角色名 |
| 生成中样式 | 居中「生成中…」标签 + 底部「取消任务」，隐藏工具栏与版本切换 |
| AI 水印 | 比例菜单下方开关，默认关闭；MOSS `output_watermark`，火山 `watermark` |
| prompt bar 展开 | 四角箭头图标，展开为居中 920×320 可编辑浮窗，点击外部/Esc 恢复 |
| 高级设置 | 齿轮按钮，和系统设置一致；面板在 prompt bar 下方弹出 |
| 画布点阵 | 浅色 `rgba(0,0,0,0.22)`、深色 `rgba(255,255,255,0.24)` |
| 资产库 | 三个 tab 的操作按钮居中，移除 tabs 底部灰线 |

## 验证

- 生成 1:1 图片后节点为正方形，工具栏显示 `1024 × 1024`
- 比例网格 6 项：1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 21:9
- 智能引用：提示词包含「图片节点 1」时开启显示「素材 1」+ 缩略图，关闭归零
- 水印请求打桩：
  - 关闭 → `output_watermark: { enabled: false }`
  - 开启 → `output_watermark: { enabled: true }`
- prompt bar 展开：920×320，输入框 238px，可编辑；点击空白恢复 760×132
- 高级设置面板：`panelTop 532 > barBottom 525`，右对齐
- 资产库三 tab 按钮中心偏差 0px，tabs 下边框 0px
- `corepack pnpm typecheck` 通过

## 待验证

- 关闭 AI 水印需要重启主进程后生成确认
