# PromptBar 输入模式与槽位方案

日期：2026-11-15
状态：P0 / P1 已实施，P2 部分实施
关联：[models.md](models.md)、[model-config-v2-plan.md](model-config-v2-plan.md)、[ui-spec.md](ui-spec.md)

## 1. 背景

当前 PromptBar 的引用逻辑是「按连线顺序自动分配角色」：

- 第 1 张图 → `firstFrame`
- 第 2 张图 → `lastFrame`
- 第 3 张图 → `reference`
- 视频 → `reference`
- 最多 3 张图 + 1 个视频

这套规则在纯图生视频场景下能用，但遇到模型差异就会误判：

- 一张图既可能是首帧，也可能是参考图、风格参考、主体参考或蒙版。
- 首尾帧和参考生视频在 Seedance、可灵、Veo 里是互斥入口。
- 图片节点根本没有「首帧」概念，但当前第一张图仍被标成 `firstFrame`。
- 用户无法指定「这张图是尾帧」「这个视频是源视频」。
- 超过 3 张图会被静默丢弃。

用户提出的「首尾帧按钮 + 超过 2 张自动取消」方向是对的，但需要扩展成一套通用的「输入模式 + 槽位」机制。

## 2. 同类产品调研

| 产品 | 交互 | 关键点 |
|---|---|---|
| LibTV | 视频节点分「首尾帧」「全能参考」等入口；用 `@素材名` 指定用途，例如「@图片1 作为首帧」 | 首尾帧与全模态参考互斥；只传首帧 + 提示词走首尾帧入口 |
| 即梦 | 图生视频默认开启；「使用尾帧」开关上传首帧/尾帧；Seedance 2.0 分「首尾帧」和「全能参考」入口 | 通过 `@图片1 作为首帧`、`@视频1 参考镜头语言` 指定用途；智能多帧、主体参考不能同时选中 |
| 可灵 | 图生视频分「首尾帧」和「多图参考」两个模式 | 首尾帧上传开场图 + 结尾图；多图参考单独入口 |
| Runway | First frame / Last frame / Reference images 分开 | 参考图自动编号 `Image 1`、`Image 2` |
| Veo | First frame / First + last frame / Ingredients 三种模式 | Ingredients 最多 3 张参考图；与首尾帧分开 |
| Sora | 单张 `input_reference`，作为首帧锚点 | 不是多图参考 |
| Vidu | 图生视频 / 首尾帧 / 参考生视频分开 | 参考图 1–15、参考音频 0–3 |

共同结论：

1. **模式是显式入口**，不是靠素材数量猜。
2. **素材放在固定槽位里**，用户知道每张图是什么角色。
3. **模式之间通常互斥**，尤其首尾帧与参考生视频。
4. **超出槽位时提示或禁用**，不静默丢弃。
5. **参考图有编号**，提示词里可以按编号引用。

## 3. 设计原则

1. 模式显式选择，自动模式只是默认值。
2. 槽位由模型 `modes` 驱动，不写死。
3. 连线素材默认填入第一个空槽，用户可以改角色。
4. 超限时自动切换模式，并给出可撤销的提示。
5. 切换模型时，模式与模型能力联动，不兼容时明确提示。
6. 旧节点没有模式字段时，继续按自动模式工作。

## 4. 模式清单

### 4.1 视频节点

| 模式 | 槽位 | 说明 |
|---|---|---|
| 自动 | 按素材推断 | 默认，不写入节点数据 |
| 文生视频 `t2v` | 提示词 | 无图片/视频 |
| 首帧 `first-frame` | 首帧 1 | 一张图 |
| 首尾帧 `first-last` | 首帧 1、尾帧 1 | 两张图，互斥参考模式 |
| 全能参考 `reference` | 参考图 0–N、参考视频 0–N、参考音频 0–N | 多模态参考，默认模式 |
| 视频编辑 `video-edit` | 源视频 1、替换图 0–1 | 对应片段重拍/元素替换 |
| 视频延长 `video-extend` | 源视频 1 | 对应智能续写 |

### 4.2 图片节点

| 模式 | 槽位 | 说明 |
|---|---|---|
| 自动 | 按素材推断 | 默认 |
| 文生图 `t2i` | 提示词 | 无参考图 |
| 图生图 `i2i` | 参考图 1–N、蒙版 0–1 | 单图/多图/蒙版 |
| 多参考图 | 参考图 2–N | `i2i` 的一种展示形态 |
| 图层拆分 `layer` | 源图 1 | 不走参考图 |

图片节点不显示首帧/尾帧/视频编辑/视频延长。

## 5. 交互设计

### 5.1 模式选择器

位置：PromptBar 工具栏左侧，在「上传」「画布参考」之前。

```
[自动 ▾]  [上传]  [画布参考]  ...
```

- 按钮显示当前模式名，例如「首尾帧」。
- 下拉只列出当前模型支持的模式；不支持的置灰并显示原因。
- 默认「自动」。如果模型只支持一种模式，自动选中并隐藏下拉，显示只读标签。
- 切换模式时：
  - 如果当前素材能放入新槽位，自动迁移。
  - 放不下的素材保留在「未使用素材」区，不丢弃。
  - 提示「已切换为首尾帧，2 张素材已放入」。

### 5.2 槽位面板

位置：输入框上方，替换现有的扁平缩略图列表。

```
首帧             尾帧
[ 空 / 缩略图 ]  [ 空 / 缩略图 ]
```

参考模式：

```
参考图 1        参考图 2        参考图 3        [+]
[ 缩略图 ]      [ 缩略图 ]      [ 空 ]         上传
```

视频编辑：

```
源视频           替换素材
[ 缩略图 ]       [ 空 / 缩略图 ]
```

- 每个槽位显示角色名、缩略图、移除按钮。
- 空槽点击后打开素材选择：本地上传 / 画布 / 资产库。
- 已连线素材自动填入第一个空槽。
- 槽位数量超过 4 个时横向滚动。

### 5.3 超限规则

| 当前模式 | 新增素材 | 行为 |
|---|---|---|
| 首尾帧 | 第 3 张图 | 自动切换「参考生视频」，3 张都作为参考图；Toast「首尾帧最多 2 张，已切换为参考图」+ 撤销 |
| 首帧 | 第 2 张图 | 模型支持首尾帧 → 自动切换首尾帧；否则切换参考图 |
| 参考生视频 | 超过槽位上限 | 不加入，提示「当前模型最多 N 张参考图」 |
| 视频编辑 | 第 2 个源视频 | 不加入，提示「源视频只能 1 个」 |
| 图片图生图 | 超过参考图上限 | 不加入，提示上限 |
| 图层拆分 | 第 2 张源图 | 不加入，提示「图层拆分只支持 1 张源图」 |

自动切换必须满足两个条件：

1. 新素材确实放不进当前模式。
2. 模型支持目标模式。

否则只提示，不切换。

### 5.4 手动指定角色

点击缩略图弹出菜单：

- 设为首帧
- 设为尾帧
- 设为参考图
- 设为替换素材
- 设为蒙版
- 移除

只显示当前模式允许的角色。例如首尾帧模式只显示首帧/尾帧/移除。

拖拽缩略图到另一个槽位可以交换。

### 5.5 模型切换联动

- 当前模式不被新模型支持：
  - 模型菜单里置灰该模型，并显示「不支持首尾帧」。
  - 如果用户已经选了不支持的模型，保留模式但提示「当前模型不支持首尾帧，请切换模型或改为自动」。
- 切换模型后：
  - 如果新模型支持当前模式，保留槽位。
  - 如果不支持，自动回退到「自动」，并 Toast 提示。

### 5.6 与视频操作节点的关系

片段重拍、元素替换、智能续写当前是独立的功能节点（`VideoOpNodeView`），不在 PromptBar 里。

- 普通视频节点的模式选择器只显示 `t2v` / `first-frame` / `first-last` / `reference`。
- 视频编辑/延长仍由功能节点负责，避免两套入口冲突。
- 后续可以把功能节点的「源视频 + 区间 + 替换图」也映射到槽位，但第一版不做。

## 6. 数据结构

### 6.1 角色扩展

```ts
export type ReferenceRole =
  | 'firstFrame'
  | 'lastFrame'
  | 'reference'
  | 'mask'
  | 'subject'
  | 'style'
  | 'source'
  | 'sourceVideo'
  | 'referenceVideo'
  | 'referenceAudio'
```

兼容规则：

- 旧 `reference` 继续表示通用参考图。
- 视频源视频继续走 `GenerateRequest.video`，`sourceVideo` 只用于槽位 UI。
- 参考视频/音频如果后续走 `refs`，用 `referenceVideo` / `referenceAudio`。

### 6.2 节点数据

```ts
export interface InputSlotValue {
  path: string
  scope?: AssetScope
  role: ReferenceRole
  kind: 'image' | 'video' | 'audio'
}

export interface CineNodeData {
  /** 用户显式选择的模式；auto 或省略表示自动 */
  inputMode?: ModelModeId | 'auto'
  /** 槽位分配；为空时按模式自动填充 */
  inputSlots?: Record<string, InputSlotValue[]>
}
```

- `inputMode` 保存用户选择，刷新后保留。
- `inputSlots` 可选。只有用户手动改过槽位时才写入，避免每个节点都存冗余数据。
- 旧节点没有这两个字段，按自动模式工作。

### 6.3 生成请求

`GenerateRequest.refs` 已经携带 `role`，不需要改协议。只需要保证 PromptBar 写入的 role 与槽位一致。

`request.video` 继续承载源视频，`videoOptions` 继续承载操作区间/方向/时长。

## 7. 模式推断与兼容

自动模式规则（保持保守）：

- 图片节点：无图 → `t2i`；有图 → `i2i`；开启图层拆分 → `layer`。
- 视频节点：无媒体 → `t2v`；1 图 → `first-frame`（如果模型支持）否则 `reference`；2 图 → `first-last`（如果模型支持）否则 `reference`；3+ 图 → `reference`；有视频 → `reference` / `video-edit` / `video-extend`。

显式模式优先于自动模式。显式模式与素材数量冲突时，按 5.3 处理。

## 9. 实施顺序

### P0：首尾帧与参考图

- 视频节点模式选择器：自动 / 首帧 / 首尾帧 / 参考生视频。
- 槽位面板：首帧、尾帧、参考图。
- 超限自动切换 + Toast + 撤销。
- 模型不支持时置灰/提示。
- 旧节点按自动模式兼容。

### P1：图片节点与蒙版

- 图片节点模式：自动 / 文生图 / 图生图 / 多参考图 / 图层拆分。
- 蒙版槽位。
- 参考图编号与提示词 `@` 引用。
- 手动角色菜单。

### P2：视频编辑/延长与参考视频/音频

- 视频编辑/延长的槽位映射。
- 参考视频、参考音频槽位。
- 拖拽排序、槽位交换。

## 10. 验收标准

1. 视频节点选「首尾帧」后，只显示首帧/尾帧两个槽位。
2. 连线 2 张图自动填入首帧/尾帧。
3. 加入第 3 张图 → 自动切换参考生视频，3 张都保留为参考图，Toast 可撤销。
4. 图片节点选「图生图」后，参考图不再被标成首帧。
5. 模型不支持当前模式时，模式置灰或明确提示。
6. 刷新项目后，模式与槽位保留。
7. 生成请求里的 role 与槽位一致。
8. 旧项目打开后按自动模式正常工作。

## 11. 风险与取舍

| 风险 | 处理 |
|---|---|
| 自动切换打断用户 | Toast + 撤销；只在新素材放不下且目标模式受支持时触发 |
| 角色扩展影响适配器 | 旧 `reference` 保持兼容；新角色只在槽位和请求映射里使用 |
| 节点数据变大 | 只有手动改过槽位才写 `inputSlots` |
| 模式选择器增加复杂度 | 默认「自动」，普通用户可以不碰 |
| 首尾帧与参考模式互斥 | 切换模式时清空不兼容槽位，素材放入「未使用素材」区 |
| 视频操作节点重复 | 普通节点不显示编辑/延长模式，保持功能节点独立 |

## 12. 实施记录

### 12.1 已完成（2026-11-15）

- 视频/图片模式选择器，自动模式按素材推断。
- 槽位条：首帧、尾帧、参考图、源视频、蒙版。
- 首尾帧超过 2 张自动切参考图，可撤销。
- 点击槽位改角色、拖拽交换角色。
- 节点错误区「检查模型配置」回链。
- 供应商表单步骤条与空状态三步引导。

### 12.2 蒙版槽位

- `i2i` 模式已有 `mask` 槽位，PromptBar 增加「蒙版」入口。
- 点击「涂抹」打开 `MaskEditorDialog`，源图为当前第一张参考图。
- 蒙版按参考图路径绑定；换参考图后自动失效，避免尺寸不匹配。
- 确认后写入 `GenerateRequest.mask`，透明区域表示需要编辑。
- 支持重新涂抹和清除；拖拽不会覆盖蒙版槽位。
- `refs.mask` 变量同时接入 `http-template` 与 `extraBody`；multipart 会自动把 data URL 转成文件字段。
- OpenAI 兼容模型走 `/images/edits` 的 `mask` 字段；其他模型需要模板里显式引用 `{{refs.mask}}`。
- 主体/风格参考不做显式适配：调研确认 LibTV 的角色一致性也是「参考图 + 资产管理」，不是特殊协议字段。PromptBar 不再提供「设为主体参考 / 设为风格参考」入口，统一按参考图 + 提示词处理；`refs.subject` / `refs.style` 变量保留给自定义协议。

### 12.3 未实施

- `inputMode` / `inputSlots` 尚未持久化到节点数据，刷新后按自动模式重建。
- 参考图编号与提示词 `@` 引用尚未做。
- 参考视频/音频槽位尚未做。

### 12.4 首尾帧与槽位合并（2026-11-15）

- Agnes 2.5 视频补齐 `first-last` 模式：适配器本来就发送尾帧，之前只是预设没声明，导致两张图时只能落在首帧。
- 自动模式分配角色时按模型能力决定：第二张图只在模型支持首尾帧时作尾帧，否则降为参考图。
- 移除 PromptBar 右上角重复的素材缩略图列表，槽位条成为唯一的素材入口。
- 模式槽位之外的素材以「未使用」槽位显示，不再被隐藏。
- 槽位缩略图支持悬停预览、双击定位节点、菜单移除。
- 切换节点时重置模式、角色覆盖和浮层状态，避免跨节点继承。

### 12.5 PromptBar 加高与槽位样式（2026-11-15）

- PromptBar 高度从 132px 增加到 196px，提示词输入区明显变大。
- 槽位改成 48×48 正方形，角色标签覆盖在图片左上角，不再单独占一行。
- 标签使用半透明表面色背景，跟随主题变量，不硬编码色值。

### 12.6 模式驱动槽位（2026-11-15）

- 去掉「自动」选项：无素材显示文生视频/文生图，有素材默认全能参考。
- `reference` 改名为「全能参考」。
- 模式选项按素材数量置灰：文生视频有图时置灰，首帧只接受 1 张，首尾帧只接受 2 张。
- 首帧/首尾帧超量时自动回退全能参考，并给出提示。
- 槽位角色完全由模式推导，移除点击改角色、拖拽交换和槽位菜单。
- 全能参考的槽位标签改为编号，空的视频/音频槽位不再显示。
- 槽位 48 → 40；模式、模型、参数三个下拉统一为无边框 chip 样式。

### 12.7 槽位拖拽排序与主题默认（2026-11-15）

- 槽位缩略图支持拖动交换位置，`refOrder` 写入节点数据并随项目保存。
- 槽位数量等于素材数量，不再显示空槽位。
- 切换节点后顺序保持；新素材追加到末尾。
- 主题默认从 `dark` 改为 `system`，只影响首次安装；已保存设置的用户保持原选择。
