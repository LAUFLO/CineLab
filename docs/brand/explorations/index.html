Logo Exploration

五条结构不同的方向 · 暗房暖光色系 · 仅供评审，尚未定稿
ROUTE A · APERTURE

A. 光圈 / 光阑

概念：叶片围合出光圈，中心留一点暖琥珀光。镜头语言直给，精密、克制。

初评：识别度最高、小尺寸最稳；但摄影类符号风险最高，需要靠开口比例与叶片手感建立差异。

ROUTE B · MONOGRAM

B. C / L 咬合

概念：C 的开口作为画布入口，L 的竖笔作为工作台边缘，两字母共享一条结构线。

初评：结构清晰、延展性好；但当前咬合感不足，更像并排字母，橙色方块位置偏悬空。

ROUTE C · DARKROOM BENCH

C. 暗房工作台

概念：显影盘与胶片框合并，一角进入暖光。Lab 的实验感 + 工作室温度。

初评：温度与工作室气质最强；但当前过于具象、带立体感，小尺寸会糊，需要重做。

ROUTE D · CANVAS COORDINATE

D. 画布坐标系

概念：四个坐标刻度 + 一条工作流曲线 + 一个琥珀节点，暗示无限画布上正在发生的工作流。

初评：最贴近产品；但线条太细、记忆点弱，更像图表工具，不建议直接采用。

ROUTE E · WORDMARK

E. 字标驱动

概念：几何无衬线字标，i 上方琥珀方框，C 与 L 带取景框刻痕。

初评：最实用、最适合启动页与文档；但字体偏常规，橙色细节太弱，需要定制字标。

REVIEW GUIDE

评审提示

先看剪影，再看细节。把图片缩小到 32px 观察是否还成立；App 图标最终要在深色与浅色背景上都成立。

本轮为探索图，不构成最终资产；选定方向后才进入精修。

设计团队初评：A 与 E 的完成度最高，B 结构最稳但需要强化咬合，C 有最好的温度但执行失败，D 概念对但形式太弱。 如果目标是「创作者工作台」而不是「相机工具」，A 需要克制摄影感，E 需要更独特的字体细节。
