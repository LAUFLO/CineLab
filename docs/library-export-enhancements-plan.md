# 资产库与导出增强方案（P3-3）

日期：2026-11-07
状态：核心完成（标签与字幕待后续）

## 已完成

### 1. 资产库多选与批量操作

- 资产库工具栏新增「选择」模式
- 卡片左上角勾选，支持全选、清空
- 批量「移动到」文件夹（复用现有文件夹树）
- 批量删除（应用内确认）
- 切换到其他文件夹时自动退出选择

### 2. 视频合成导出

- 选中 2 个及以上视频时可「合成视频」
- 合成面板提供导出预设：
  - 分辨率：720P / 1080P
  - 画质：标准（CRF 23）/ 高画质（CRF 18）
- 按资产列表顺序拼接，统一 H.264 + AAC，输出 MP4
- 主进程 `src/main/media/concat.ts`：
  - 每个片段先统一分辨率、帧率（30fps）、SAR、编码
  - 无音频片段自动补静音轨
  - concat demuxer 无损拼接，`+faststart`
- IPC `export:concat-videos`，保存位置由系统对话框选择
