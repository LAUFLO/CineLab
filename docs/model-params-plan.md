# 模型参数编辑器方案

日期：2026-11-07
状态：已完成
关联：`docs/models.md`、P1-1

## 现状

- `ModelDef.params` 已经是完整参数模型（select/number/text/boolean）
- PromptBar 能渲染参数，但只支持 select 展开菜单；number/text/boolean 点击无反应
- 设置页只能删除模型，不能编辑参数；手动输入模型 ID 时 `params` 为空，prompt bar 不显示尺寸/比例
- 内置 `MODEL_PRESETS` 的参数对用户不可见、不可改

## 目标

- 设置页可以为每个模型配置参数
- 按能力提供模板：尺寸、画幅比例、数量、质量、时长、分辨率、声音、语速、格式、温度等
- 支持手动添加自定义参数
- PromptBar 能编辑 select/number/text/boolean 四类参数
- 保存进 `models.json`，生成链路无需改动

## 设计

### 1. 参数模板

新增 `src/shared/param-presets.ts`：

| 能力 | 模板参数 |
|---|---|
| 图片 | 尺寸、画幅比例、数量、质量、随机种子 |
| 视频 | 画幅比例、时长、分辨率、生成音频、帧率 |
| 音频 | 声音、语速、格式 |
| 文本 | 温度、最大 token |

模板带一句用户说明，例如「竖屏短剧选 9:16」「不确定时选自动」。

模板只提供 `ParamDef`，参数 key 与各适配器约定一致（`size/ratio/n/quality/duration/resolution/voice/speed/format/temperature/max_tokens`）。

### 2. 参数编辑器

新增 `src/renderer/src/canvas/nodes/ModelParamsDialog.tsx`（设置页使用）：

- 顶部「常用参数」卡片网格，每张卡片带说明、默认值/选项数和「+ 添加」；支持「全部添加」
- 已存在的 key 置灰，不会重复添加
- 参数行结构化编辑：
  - 显示名、控件类型、分组
  - 接口字段名收进「高级」折叠项，默认不展示
  - select：逐行「显示名 / 接口值」编辑，支持新增/删除选项和默认选项
  - number：默认值、最小值、最大值
  - text：默认文本
  - boolean：开启/关闭
- 选项不再手写 `值|显示名` 文本格式
- 支持删除参数和添加自定义参数
- 保存前校验：显示名/字段名必填、字段名不重复、select 至少一个选项、数字默认值有效、min ≤ max
- 时长参数特殊处理：
  - 如果模型只支持固定档位（4/5/8/10s），保留下拉选项
  - 如果模型支持连续秒数，点「改为时长滑条」，自动取选项最小/最大值并切换为数字参数
  - Prompt Bar 对 `duration` 数字参数渲染为 1 秒步进滑块，例如 4–12 秒任意整数
- 保存后写回 `draft.models`，再随供应商保存到 `models.json`

### 3. PromptBar

- 同一模型的参数合并为一个「生成设置」按钮，摘要显示前 4 个选中值（如 `16:9 · 2K · 标准画质 · 1 张`）
- 点击展开分组面板：
  - `ratio` 参数渲染为比例卡片网格（带方向图标）
  - `select` 参数渲染为选项按钮
  - `allowCustom: true` 的下拉参数在选项末尾显示「自定义」，点击后出现输入框
  - `boolean` 参数渲染为开启/关闭
  - `duration` 数字参数渲染为滑块
  - 其他 number/text 参数渲染为输入框
- AI 水印开关保留在面板底部

自定义值示例：

- 画面比例：输入 `2:1`、`2.35:1`
- 尺寸：输入 `2048x1152`、`1536x640`
- 分辨率：输入 `2K`

自定义值不要求在预设 options 中；`ParamDef.allowCustom` 由模型参数编辑器勾选「允许在生成设置中自定义值」控制。

### 4. 参数分组

`ParamDef.group` 控制面板分组；模板已内置「尺寸 / 比例 / 清晰度 / 画质 / 视频时长 / 生成音频 / 声音 / 语速 / 格式 / 生成数量」等分组。旧参数没有 `group` 时归入「其它」。

### 4. 校验

保存供应商时沿用 `models-config.ts` 的参数校验：

- key/label/type 必填
- select 必须有 options
- 默认值类型与参数类型一致

## 验收

- 设置页模型卡片有「参数」入口
- 首次打开能看到常用参数卡片和说明
- 主区域不出现接口字段名，只有折叠的「高级」项
- 点「全部添加」后出现尺寸/比例/数量/质量/种子参数
- 下拉选项用「显示名 / 接口值」逐行编辑，不再手写竖线格式
- 尺寸/比例参数可勾选「允许在生成设置中自定义值」
- 时长下拉可一键「改为时长滑条」，自动得到 min/max，Prompt Bar 可滑 4–12 任意秒
- Prompt Bar 中比例/尺寸出现「自定义」，可输入 `2:1`、`2048x1152` 等
- 保存后重新打开设置，参数仍在
- PromptBar 出现对应生成设置
