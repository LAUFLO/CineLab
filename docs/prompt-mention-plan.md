# 提示词输入框：@ 引用与持久化方案

日期：2026-11-07
状态：已实施

## 问题

1. 生成完成或切换节点后，Prompt Bar 中的提示词丢失
2. 「智能引用 AutoLink」开启后缺少可见反馈，用户无法判断是否生效
3. 缺少 `@` 快捷引用入口，无法从画布连线和资产库直接挑素材
4. Prompt Bar 的「角色」下拉按钮不需要，角色应统一走引用入口
5. 画布参考提示条的「取消」按钮点击无响应

## 方案

### 1. 提示词按节点持久化

- `CineNodeData` 新增可选字段 `prompt?: string`
- Prompt Bar 当前文本读取 `node.data.prompt`
- 输入时本地状态即时响应，350ms 防抖写回节点
- 切换节点、组件卸载时立即写回上一个节点
- 生成完成不修改 `prompt`，因此提示词保留
- 项目保存沿用节点 JSON，无需额外迁移

### 2. `@` 引用菜单

- 在输入框中输入 `@`（行首或空白后）弹出菜单
- 继续输入即过滤候选
- 菜单分组：
  - 已引用：当前连线、画布参考、AutoLink 已匹配的素材
  - 画布：其它有图片输出的节点
  - 资产库：图片与模板资产
  - 角色：角色卡（插入后引用其全部参考图）
- 键盘：↑/↓ 移动、Enter 选择、Esc 关闭
- 选择后：
  - 文本插入 `@名称 `
  - 对应素材加入引用列表（生成时提交）
  - 输入框内以强调色 token 样式显示

### 3. 输入框 token 高亮

- 使用 textarea + 同步镜像层
- textarea 文字透明、保留光标和选区
- 镜像层按相同字体/行高/内边距渲染，命中 `@名称` 时套用 token 样式
- 只对已进入引用列表的名称高亮，避免误伤普通文本

### 4. AutoLink 可见反馈

- 引用缩略图区显示「AutoLink N」
- 自动匹配的缩略图加虚线描边
- 高级设置描述补充匹配结果会进入素材缩略图

### 5. 删除角色按钮

- 移除 Prompt Bar 的「角色」下拉与角色菜单
- 移除 `characterIds` 状态和角色引用拼接
- 角色卡保留在 `@` 菜单中

### 6. 画布参考取消按钮

- 画布参考的全局 pointerdown 拦截跳过 `.canvas-pick-bar`
- 取消按钮点击直接 `setPicking(false)`
- 不影响在画布上点选节点

## 验收

- 输入提示词 → 切换节点 → 切回，文本仍在
- 生成后文本仍在
- 输入 `@` 出现菜单，能按名称过滤
- 选择画布节点或资产后，输入框出现高亮 `@名称`，引用缩略图增加
- 角色按钮消失
- 点击「画布参考」→ 顶部提示条 → 取消，提示条关闭
- AutoLink 匹配时显示数量与描边
