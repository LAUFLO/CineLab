# 底部工具栏改造计划

> 状态：已确认，排在分组节点（GROUP-1）之后实现
> 日期：2026-11-05

## 决策

- 资产库入口保留在左下 `StatusBar`，不迁入底部中间工具栏
- 中间 `BottomBar` 只放高频命令与工具
- 先做 P0 + P1，P2 命令面板后置
- 不照搬 LibTV 的视频/图片 AI 编辑工具集

## 布局分工

### 中间 BottomBar

```
+ | 选择/抓手 | 生成历史 | 快捷键 | 设置 | Agent
```

- `+`：打开添加节点菜单
- 选择 / 抓手：V / H 切换，按住 Space 临时抓手
- 生成历史：打开历史面板
- 快捷键：打开快捷键面板
- 设置：打开现有设置面板
- Agent：保留占位

### 左下 StatusBar

```
资产管理 | 整理 | 适应视图 | 连线 | 吸附 | 小地图 | 缩放
```

资产库入口继续留在这里。

## P0：让 BottomBar 可用

1. `+` 打开添加节点菜单，位置为视口中心
2. `V` 选择模式、`H` 抓手模式
3. 按住 `Space` 临时抓手，松开恢复
4. 设置按钮打开设置面板
5. 快捷键按钮打开快捷键面板
6. 删除或隐藏没有实现的占位按钮
7. 给当前工具加选中态

## P1：添加入口与查找

### 添加菜单

```
添加节点
  文本
  图片
  视频
  音频

添加资源
  上传
  从生成历史选择
```

- 上传：复用现有导入素材 + 在画布创建节点
- 从生成历史选择：列出历史输出，点击创建对应节点

### Ctrl+F 节点搜索

- 输入关键词过滤节点标题、类型、提示词
- 键盘上下选择，Enter 定位
- 定位方式：fitView 到节点
- 无结果时显示空状态

### 生成历史

- 按时间倒序列出节点输出
- 显示缩略图、类型、模型、时间、来源节点
- 操作：定位节点、添加到画布、保存到资产库、导出

## P2：命令面板

`Ctrl+K` 搜索所有已有动作：

- 添加图片 / 视频 / 音频 / 文本
- 打组 / 合并分组 / 解组
- 导出项目 / 导出选中
- 整理画布 / 适应视图
- 打开设置 / 资产库

只列真实存在的动作，不放未接入的 AI 编辑能力。

## 不复刻

- 去字幕、逐帧拉片、片段重拍
- 智能抠像、元素替换、主体消除、分离音视频
- 图层分离、720 度全景、九宫格、打光、扩图
- 风格库 / 特效库
- 官方角色库
- 触摸板手势

这些属于后期编辑工具链或内容生态，当前不做。

## 技术要点

- `BottomBar` 当前按钮大多没有 `onClick`，先补事件
- React Flow 的 `panOnDrag` 按工具切换：
  - 选择模式：`panOnDrag={[1]}` + `selectionOnDrag`
  - 抓手模式：`panOnDrag={true}` + `selectionOnDrag={false}`
- `Space` 临时抓手通过 keydown/keyup 切换，输入框内忽略
- 快捷键面板复用应用内浮窗样式，与设置面板平级
- 节点搜索需要访问节点 DOM 做 `fitView`，不要改画布数据结构
- 生成历史从 `node.data.outputs` 聚合，不新增持久化格式
