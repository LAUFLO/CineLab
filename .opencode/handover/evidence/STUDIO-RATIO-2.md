# STUDIO-RATIO-2 · 六种画幅与时间线缩略图不裁剪

日期：2026-11-09

## 1. 画幅补齐为 6 种

属性面板的画幅按钮从 3 个扩展为 6 个，按用户给出的顺序排列：

| 画幅 | 分辨率 |
|---|---|
| 9:16 | 1080×1920 |
| 16:9 | 1920×1080 |
| 21:9 | 2560×1080 |
| 3:4 | 1080×1440 |
| 4:3 | 1440×1080 |
| 1:1 | 1080×1080 |

布局改为 3 列 2 行，按钮自适应宽度。

首个素材自动匹配画幅的范围同步扩展：

- ratio ≥ 1.9 → 21:9
- ≥ 1.45 → 16:9
- ≥ 1.15 → 4:3
- ≥ 0.88 → 1:1
- ≥ 0.72 → 3:4
- 其余 → 9:16

## 2. 时间线缩略图不再裁剪

- 竖屏素材（ratio < 0.9）在时间线片段里改用「重复平铺」背景：`background-size: auto 100%` + `repeat-x`，按原始比例重复显示完整画面，不再被压成横向条。
- 普通素材的 `.studio-clip__frames img` 从 `object-fit: cover` 改为 `contain`。
- 素材池缩略图 `.studio-pool__thumb-img` 和单媒体 `.studio-clip__media` 同步改为 `contain`，9:16 素材在素材列表里也能完整看到。

## 验证

- `typecheck`、27 文件 / 162 用例、`build` 通过。
- 隔离实例实测：
  - 画幅按钮显示 `9:16 / 16:9 / 21:9 / 3:4 / 4:3 / 1:1`，当前 9:16 高亮。
  - 拖入 540×960 竖屏素材后，时间线自动变为 1080×1920。
  - 预览完整显示竖屏画面（左右黑边），不裁剪。
  - 时间线缩略图按竖屏比例重复平铺，不再裁成横条。
