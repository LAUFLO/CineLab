# DEPTH-CAPTURE UI 调整

日期：2026-11-06
方案：`docs/depth-capture-plan.md`

## 变更

### 1. 工具栏置顶

- `node-operations.ts` 的 `motion-capture` 从「更多」移到视频一级第一个
- `defaultPrimary: true`，`section: 'video'`

视频节点工具栏顺序：
`深度动作捕捉 | 片段截取 | 分离音视频 | 抽帧 | 画面裁切 | 更多 | 下载 | 展开`

### 2. 设置入口改为「组件」

- `SettingsPanel.tsx` 导航项从「深度组件」改为「组件」
- 定位为通用组件管理入口，后续其他本地能力复用

### 3. 组件卡片

- 全称：
  - 深度动作捕捉运行时
  - Video Depth Anything Small 模型
- 每个组件增加详细简介，说明用途和影响的功能
- 已安装操作从「删除」改为「卸载」

### 4. 卸载二次确认

使用全局 `requestConfirm`：

```
标题：卸载「深度动作捕捉运行时」？
正文：卸载后，「深度动作捕捉」将无法使用。已生成的深度视频节点不受影响，可随时重新下载。
按钮：取消 / 卸载（danger）
```

### 5. 未安装引导

点击节点「深度动作捕捉」时先检查两个组件：

- 未安装：弹出确认窗
  - 标题「需要先安装深度组件」
  - 说明需要的两个组件和约 375MB 体积
  - 按钮「取消 / 前往设置」
  - 「前往设置」直接打开设置并切到「组件」页
- 已安装：继续打开参数对话框
