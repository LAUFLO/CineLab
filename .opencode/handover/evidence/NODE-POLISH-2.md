# NODE-POLISH-2 · 音频控制条上移、文本节点占位图标

日期：2026-11-09

## 1. 音频控制条被提示词栏遮挡

- 现象：音频节点的播放/时间控制条在卡片底部，节点靠近画布底部时会被 Prompt Bar 盖住。
- 处理：控制条移到波形上方（标题栏下方），波形仍铺满剩余空间；分隔线从 `border-top` 改为 `border-bottom`。
- 实测：节点位于底部时 `00:00 ▶ 00:02` 完整可见，不再与 Prompt Bar 重叠。

## 2. 文本节点出现三条杠

- 现象：有内容的文本节点中间出现 3 条灰色横线。
- 根因：`!assetSrc` 分支无条件渲染占位图标（text 图标就是三条横线），文本内容又在绝对定位层显示，两者叠加。
- 处理：文本节点已有 `data.text` 时不再渲染占位图标。
- 实测：文本节点只显示 Markdown 内容，无占位图标。

## 验证

- `corepack pnpm typecheck` 通过。
- 隔离实例截图确认音频控制条在波形上方、文本节点无占位图标。
