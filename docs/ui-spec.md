# CineLab UI 规格

日期：2026-11-13
状态：现行
适用版本：v0.1.0
最后核对：2026-11-13

> 目标：保持 LibTV 式无限画布体验，同时覆盖 CineBot、剪辑室、导演台和逐帧拉片。
> 基准分辨率 1920×1080，所有尺寸单位为 px。
> 第 1–13 节是画布基础规格；第 14–18 节是后续新增界面。具体数值以 CSS 变量和组件实现为准。

---

## 1. 设计原则

1. **画布优先**：除顶栏、底部工具条、左下状态区外，不设任何常驻面板。
2. **节点轻，参数重**：节点只负责预览与快捷模板，所有生成参数收进节点下方的 prompt bar。
3. **创建即连接**：拉线到空白处直接弹出节点菜单，选中即在落点建节点并自动连线，一步完成。
4. **默认安静**：`+` 按钮仅悬停出现，连线默认低透明度，只有选中或拖拽时才高亮。
5. **深色为主，浅色为选**：两套主题共用同一组 CSS 变量，组件不写死颜色。

### 2.1 顶栏

- 高度 **40px**，绝对定位 `top: 0`，左右 padding **12px**。
- 背景透明，直接浮在画布上；只有子元素接收鼠标事件（`pointer-events: none` 于容器，子元素 `auto`）。
- 左侧组与右侧组分别用 `flex`，中间留空。

**左侧组**

|---|---|---|

| 工作区名 | 13px，`--text-1`，最大宽 180px 省略号 | 双击重命名 |
| 分隔线 | 1×16，`--divider` | — |
| 画布切换 | 13px，右侧 `chevron-down` 12px | 点击展开画布列表，支持重命名/复制/删除/新建 |
| 框选按钮 | 28×28 | 切换框选模式 |
| 分屏按钮 | 28×28 | 切换双画布对比视图（第一版不做，置灰） |

**右侧组**

| 元素 | 替换自 LibTV | 规格 |
|---|---|---|
| 导出 | 分享 | 28×28，点击弹出：导出项目 / 导出当前画布 PNG / 导出选中素材 |
| API 消耗 | ⚡100 积分 | 文本按钮，`¥12.40`，13px；点击打开消耗明细面板 |

| 设置 | 头像 | 28×28 圆形，点击打开设置 |

> LibTV 的「开通会员」和活动标签直接删除，不占位。

### 2.2 底部工具条

- 尺寸：宽 **380px**，高 **40px**，圆角 **12px**，`bottom: 16px` 水平居中。
- 背景 `--surface`，边框 1px `--border`，阴影 `--shadow-float`。
- 按钮 32×32，图标 16px，按钮间距 2px，整条 padding 4px。

| 顺序 | 图标 | 功能 |

| 4 | history | 生成历史面板 |
| 5 | help | 快捷键速查 |
| 6 | settings | 设置 |
| 7 | agent | AI 助手（第一版置灰） |

> 第 7 个是 28px 青色圆形按钮，与 LibTV 一致。

### 2.3 左下状态区

- 距左 **12px**，距底 **12px**，高 **24px**，字号 12px，颜色 `--text-2`。
- 项之间间距 16px。

| 项 | 图标 | 行为 |
|---|---|---|
| 资产库 | folder | 打开资产抽屉 |
| 网格 | grid | 开关点阵网格 |
| 水印 | droplet | 开关水印 |
| 导出 | download | 同顶栏导出 |
| 缩放 | — | 显示当前百分比，点击弹出 25/50/100/200/适应画布 |

### 2.4 画布

- 占满整个窗口，无边框。
- 点阵网格：间距 **16px**，点半径 1px，颜色 `--grid-dot`。
- 网格随画布缩放，但缩放到 25% 以下时自动隐藏，避免摩尔纹。
- 画布平移范围不限，缩放范围 **10% – 400%**。
- 底部工具条和左下状态区浮在画布之上，不挤压画布。

### 3.5 Tailwind 主题映射

`styles/tailwind.css` 用 `@theme` 把现有 tokens 映射为 Tailwind 主题；`styles/base.css` 负责 `color-scheme` 和文本选择；`global.css` 保留现有手写样式，迁移期逐步删除。

| Tailwind token | 来源 CSS 变量 | 典型类 |
|---|---|---|
| `--color-canvas` | `--canvas-bg` | `bg-canvas` |
| `--color-surface` | `--surface` | `bg-surface` |
| `--color-surface-raised` | `--surface-raised` | `bg-surface-raised` |
| `--color-fg` | `--text-1` | `text-fg` |
| `--color-fg-muted` | `--text-2` | `text-fg-muted` |
| `--color-fg-subtle` | `--text-3` | `text-fg-subtle` |
| `--color-border` | `--border` | `border-border` |
| `--color-accent` | `--accent` | `bg-accent` / `text-accent` |
| `--color-success/warning/danger` | 同名状态色 | `text-success` 等 |
| `--radius-card/panel/pill` | 新增圆角尺度 | `rounded-card` 等 |
| `--shadow-float/menu/node` | 同名阴影 | `shadow-float` 等 |

新组件优先使用上述语义类，不要使用 Tailwind 默认色板（如 `bg-slate-800`）或硬编码色值。动态画布尺寸、时间线定位和 3D 参数继续使用 CSS 变量/inline style。

## 4. 节点规格

### 4.1 通用结构

```
┌ 📄 文本节点 1              ← 标题行，高 28px，在卡片外部
┌───────────────────────┐
│                       │
│        卡片内容        │   ← 卡片，圆角 12px，背景 --surface-raised
│                       │
└───────────────────────┘
(+)                   (+)  ← 悬停时出现在左右两侧
```

| 属性 | 规格 |
|---|---|
| 节点容器 | 宽度固定，高度 = 28px 标题 + 卡片高；背景透明 |
| 标题行 | 高 28px，字号 12px，颜色 `--text-2`，图标 12px，左对齐，内边距 4px |
| 卡片 | 圆角 12px，1px 边框 `--border`，背景 `--surface-raised`，`overflow: hidden` |
| 悬停 | 边框变 `--border-strong`，标题变 `--text-1` |
| 选中 | 卡片 1.5px 描边 `--border-selected`，`+` 常显 |
| 拖拽中 | 整体 `opacity: .9`，`cursor: grabbing` |
| 生成中 | 卡片右上角显示 2px 进度环 |

四种节点的尺寸：

| 类型 | 卡片尺寸 | 总高（含标题） |
|---|---|---|
| 文本 | 348 × 348 | 376 |
| 图片 | 614 × 348 | 376 |
| 视频 | 614 × 348 | 376 |
| 音频 | 348 × 220 | 248 |

### 4.2 卡片内部（通用布局）

```
┌─────────────────────────────┐
│                             │
│         内容预览区           │  ← 占满剩余空间，居中显示
│                             │
│  尝试：                      │  ← 快捷模板区，底部对齐
│  ▪ 自己编写内容              │
│  ▪ 文生视频                  │
└─────────────────────────────┘
```

- 内容预览区：有内容时显示图片/视频封面/文本摘要；空时显示类型占位图标（山峰、播放、文档、波形），颜色 `--text-3`，尺寸 40px。
- 「尝试：」标签：11px，`--text-3`，左内边距 16px。
- 模板项：高 26px，字号 13px，`--text-2`，图标 14px；悬停时背景 `--surface-hover`、文字 `--text-1`。
- 卡片内边距：上 0，左右 16px，下 12px。

### 4.3 四类节点的差异

**文本节点**（348×348）
- 预览区：文本摘要，最多 6 行，14px/22px，超出省略。
- 空态：居中的文档图标 + 四条横线。
- 编辑弹窗：单栏，工具栏提供「预览 / Markdown」切换；格式工具只在 Markdown 编辑态显示。
- 默认模板：自己编写内容、文生视频、图片反推提示词、文学生成音乐。

**图片节点**（614×348）
- 预览区：16:9 图片，`object-fit: cover`。
- 空态：山峰图标居中。
- 默认模板：图生图、图片高清。

**视频节点**（614×348）
- 预览区：16:9 视频，未播放时显示封面 + 48px 播放按钮。
- 空态：播放图标居中。
- 默认模板：首尾帧生成视频、音效生成视频、5 秒视频。

**音频节点**（348×220）
- 预览区：波形图，高 64px，颜色 `--text-3`；下方显示时长。
- 空态：波形占位 + 00:00。
- 默认模板：文字转语音、音乐生成。

### 4.4 「尝试」模板系统

每个模板是一个对象，点击后向 prompt bar 注入参数：

```ts
interface NodeTemplate {
  id: string
  label: string
  icon: string
  action:
    | { type: 'focus-prompt' }          // 只聚焦输入框
    | { type: 'patch'; patch: Partial<PromptDraft> }  // 预填模型/模式/参数
  requireCapability?: Capability        // 没配对应模型时置灰
}
```

- 模板来自三处：内置默认、模型能力自动生成、用户自定义（存项目设置）。
- `requireCapability` 不满足时，该项置灰并显示 tooltip「未配置该模型」。
- 点击模板不立即生成，只是预填；用户确认后再点发送。

## 5. 节点交互

### 5.1 左右 `+` 按钮

| 属性 | 规格 |
|---|---|
| 尺寸 | 20×20 圆形 |
| 位置 | 垂直居中，水平距卡片边缘 10px（在节点外部） |
| 图标 | plus，12px |
| 默认 | `opacity: 0`，`pointer-events: none` |
| 悬停节点 | `opacity: 1`，150ms ease-out 淡入 |
| 悬停按钮本身 | 背景 `--surface-hover`，边框 `--border-strong` |
| 选中节点 | 常显 |
| 左侧 | target handle，接入上游 |
| 右侧 | source handle，生成下游 |

### 5.2 拉线创建流程

```
① 悬停节点        → 左右 + 淡入
② 从 + 按下拖动    → 贝塞尔曲线跟随鼠标，蓝色 + 8px 发光，端点圆点放大
③ 经过其他节点     → 目标节点卡片描边高亮，+ 放大
④ 在空白处松开     → 以落点为左上角弹出菜单（右侧「引用该节点生成」/ 左侧「选择上游节点」）
⑤ 在节点上松开     → 直接建立连接，无菜单
⑥ 选菜单项         → 在落点创建节点，自动连线，新节点选中，prompt bar 出现，焦点进入输入框
⑦ 按 Esc           → 取消，连线消失，不创建节点
```

补充规则：

- 从 `+` 单击不拖动：直接弹出菜单，新节点创建在原节点右侧 **80px**、垂直居中对齐。
- 拖动过程中按 Esc：取消。
- 拖到自身：不响应。
- 拖到画布边缘外：自动平移（边缘 40px 触发，速度随距离加快）。

### 5.3 连接规则

- 每个节点左右各只有一个视觉端口，但**允许任意多条连线**。
- 输出不限条数。
- 输入默认不限条数，由目标节点的参数决定如何使用（见 5.4）。
- 不允许形成环：检测到环时，连线变红并回弹，提示「不能连接到上游节点」。
- 同一条边重复建立时，忽略第二次。

### 5.4 连线的语义

连线只表示「引用」，具体角色由目标节点类型自动推断：

| 目标节点 | 素材类型 | 默认角色 |
|---|---|---|
| 图片 | 图片 | 参考图 |
| 视频 | 图片（第一条） | 首帧 |
| 视频 | 图片（第二条起） | 参考图 |
| 视频 | 视频 | 参考视频 |
| 文本 | 任意 | 上下文素材 |
| 音频 | 文本 | 配音文本 |

需要精确控制时，在 prompt bar 的素材区点击该素材，弹出 `首帧 / 尾帧 / 参考` 三选一。默认不打扰。

### 5.5 添加节点菜单

由三种入口触发，内容一致：双击画布空白、点击底部工具条 `+`、点击节点 `+`。

```
┌─ 引用该节点生成 ──────────┐     ← 无上游来源时标题为「添加节点」
│ 🔍 搜索节点…              │     ← 高度 32px，可选
├───────────────────────────┤
│ 📄 文本                   │
│ 🖼 图片                   │
│ 🎬 视频                   │
│ 🎵 音频                   │
│ 📜 脚本              ›    │     ← 子菜单：旁白 / 对白 / 分镜描述
├───────────────────────────┤
│ ↩ 参考节点                 │     ← 仅拉线场景出现
└───────────────────────────┘
```

| 属性 | 规格 |
|---|---|
| 宽度 | 200px |
| 圆角 | 10px |
| 背景 | `--surface`，1px `--border`，`--shadow-menu` |
| 内边距 | 4px |
| 项高 | 32px，字号 13px |
| 图标 | 16px，`--text-2` |
| 悬停 | 背景 `--surface-hover` |
| 标签 | 右侧 10px 小标签，`NEW` / `Beta` / 模型名 |
| 不可用项 | `opacity: .4`，不可点击，tooltip 说明原因 |
| 展开方向 | 靠近屏幕底部时向上展开，靠近右侧时向左展开 |

「参考节点」特殊行为：不创建节点，而是二级菜单列出画布上所有可用节点（缩略图 24px + 标题），点选后建立连接。

## 6. 连线视觉

| 状态 | 颜色 | 线宽 | 附加 |
|---|---|---|---|
| 默认 | `--border-strong` | 1.5px | 无 |
| 悬停 | `--text-3` | 1.5px | 无 |
| 所在节点被选中 | `--link` | 2px | 4px 外发光 |
| 拖拽中 | `--link` | 2px | 8px 外发光，端点圆点 6px |
| 生成中 | `--accent` | 2px | 虚线流动动画，周期 1s |
| 错误 | `--danger` | 2px | 无动画 |

- 曲线类型：`bezier`，水平控制点偏移 = 两节点水平距离的 0.5 倍。
- 端点：4px 实心圆，颜色与线一致，默认 `opacity: .6`。
- 深色模式默认线为 `rgba(255,255,255,.18)`，浅色为 `rgba(0,0,0,.15)`。
- 生成中的流动动画使用 `stroke-dasharray` + `stroke-dashoffset`，避免使用 filter 动画以降低 GPU 开销。
- 300 条以上连线时，关闭悬停效果与发光，只保留选中高亮。

## 7. Prompt Bar

节点的生成参数全部收在这里，节点卡片本身不放任何输入控件。

### 7.1 位置与尺寸

| 属性 | 规格 |
|---|---|
| 宽度 | 760px（可视宽度不足时缩至 `min(760px, 屏幕宽 - 64px)`） |
| 高度 | 折叠 132px / 展开 220px |
| 位置 | 跟随选中节点，节点下方 16px，水平与节点居中对齐 |
| 圆角 | 14px |
| 背景 | `--surface`，1px `--border`，`--shadow-float` |
| 入场 | 从节点方向淡入 + 上移 8px，180ms ease-out |
| 跟随 | 节点拖动时实时跟随（`requestAnimationFrame` 节流） |
| 边界 | 超出视口时自动翻转到底部/上方或水平偏移 |

同一时刻只显示一个 prompt bar，切换选中节点时内容整体替换，不做位移动画。

### 7.2 三行结构

```
┌──────────────────────────────────────────────────────────┐
│ +上传  ◫画布参考                                    ⤢   │  36px
├──────────────────────────────────────────────────────────┤
│                                                          │
│  描述你想要生成的画面内容，@引用素材                      │  64px
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 🎬 li 2.0 ▾ │ 文生视频 ▾ │ 16:9·720P·5s·1个 ▾ │ ⚡135 │ ↑│  32px
└──────────────────────────────────────────────────────────┘
```

### 7.3 第一行：素材与工具

| 按钮 | 行为 | 适用节点 |
|---|---|---|
| `+ 上传` | 打开文件选择，上传的素材作为参考 | 全部 |
| `◫ 画布参考` | 进入拾取模式，点击画布上任意节点引用其输出 | 全部 |
| `◉ 标记` | 在图片上涂抹区域（蒙版/局部编辑） | 图片 |
| `🎨 风格` | 展开风格预设 | 图片 |
| `⋯ 更多` | 负面提示词、种子、随机种子锁定、高级参数 | 全部 |
| `⤢` | 展开为全屏编辑器 | 全部 |

角色不再单独放按钮，统一通过输入框 `@` 引用。

### 7.4 第二行：输入区

- 多行文本框，最小 64px，最多 6 行后内部滚动。
- 字号 14px，行高 20px，占位符 `--text-3`。
- 输入 `@` 弹出引用菜单，分组显示已引用、画布节点、资产库和角色卡；继续输入可过滤。
- 菜单支持 ↑/↓ 移动、Enter 选择、Esc 关闭。
- 选择后插入 `@名称`，并加入素材引用；输入框内以蓝色 token 样式显示。
- 提示词按节点保留：切换节点、生成完成、重新打开项目后都恢复。
- 支持 `{{变量}}` 语法，引用角色设定字段。
- `Shift + Enter` 换行，`Enter` 发送；输入法组合状态下不误发送。
- 生成中时输入框保持可编辑，可以排队下一条。

### 7.5 第三行：参数行（动态生成）

参数项由当前模型的 `params` schema 决定，顺序固定为：**模型 → 模式 → 规格 → 消耗**。

**图片模型示例**

```
[🎨 Lib Image 2.5 Pro ▾] [16:9 ▾] [标准画质 ▾] [2K ▾] [1张 ▾]   ⚡15   [↑]
```

**视频模型示例**

```
[🎬 li 2.0 ▾] [文生视频 ▾] [16:9 ▾] [720P ▾] [5s ▾] [1个 ▾]   ⚡135  [↑]
```

**文本模型示例**

```
[🤖 GPT-4.1 ▾] [温度 0.7 ▾] [4096 tokens ▾]                    ⚡3    [↑]
```

规则：

- 每个下拉项宽 60–140px，字号 12px，悬停显示完整值。
- 参数按「常用 → 高级」排列，最多显示 6 个，其余收进 `⋯`。
- 超出模型能力范围的参数自动隐藏，不显示禁用项。
- 消耗值根据模型定价和参数实时估算，生成后以实际为准。
- 发送按钮：36×36 圆形，默认 `--text-3` 背景；可发送时变 `--text-1`；生成中变为停止按钮（方块图标）。
- 键盘 `Ctrl+Enter` 等同发送。

### 7.6 素材区

第一行与输入区之间的素材缩略图行（有素材时出现，高度 44px）：

```
[图1 ×] [图2 ×] [视频1 ×] [角色:小雨 ×]
```

- 缩略图 36×36，圆角 6px。
- 点击缩略图可设置角色（首帧/尾帧/参考）。
- `×` 移除该素材及其连线。
- AutoLink 自动匹配的缩略图使用虚线描边，并在旁边显示 `AutoLink N`。
- 素材来自：上传、画布参考、连线、`@` 引用。

### 7.6.1 模型可用性

- 模型菜单按当前节点的引用动态判断：有参考图时，`inputs` 不含 `image` 的模型置灰并显示「不支持图片」；有参考视频时，`inputs` 不含 `video` 的模型置灰并显示「不支持视频」。
- 置灰项保留在菜单里，点击会提示缺少的输入类型，不会切换模型。
- 当前已选模型因新增引用变得不可用时，模型 chip 显示红色警告，提交时拦截并提示；不会自动切换模型。
- 图片节点不能引用视频输出；画布参考和 `@` 菜单只显示当前节点允许的素材类型。
- 模型输入能力由设置页「输入能力」维护，缺省按 `capability`、模型名和 http-template 模板推断。

### 7.7 各节点类型的差异

| 节点 | 第一行按钮 | 参数项 | 占位符 |
|---|---|---|---|
| 文本 | 上传、画布参考、更多 | 模型、温度、max tokens | 写下你想讲的故事、场景或角色设定… |
| 图片 | 上传、画布参考、标记、风格、更多 | 模型、比例、画质、分辨率、张数 | 可直接文生图，或上传图片输入文字指令对图片进行编辑… |
| 视频 | 上传、画布参考、`@` 引用 | 模型、比例、分辨率、时长 | 描述你想要生成的画面内容，@引用素材 |
| 音频 | 上传、画布参考、更多 | 模型、语言、音色、语速 | 输入要朗读的文本，或描述想要的音乐… |

### 7.8 视频操作节点

点击视频节点工具栏的「片段重拍 / 元素替换 / 智能续写」会在源节点右侧创建一个功能节点并自动连线，不再使用浮窗。

- 功能节点类型固定为创建时的操作，不能在节点内切换功能；再次点击同一按钮会选中并展开已有节点。
- 参数区在节点卡片内展开：
  - 源视频预览。
  - 缩略帧条 + 开始/结束滑块（片段重拍 / 元素替换）。
  - 替换素材：上传图片、画布图片、资产库图片（元素替换）。
  - 模型列表：未声明对应操作、不是 http-template 或缺少模板的模型置灰并显示原因。
  - 描述和开始生成。
- 点击开始生成后创建一个普通视频结果节点并连线，功能节点保留，可修改参数后再次生成。
- 时间区间第一版为缩略帧条 + 双滑块，后续复用剪辑台时间轴。

## 14. CineBot 面板

CineBot 是全局浮层，不占用画布布局。

- 位置：右下角，`right: 12px`、`bottom: 16px`，宽度 420px，最大宽度 `calc(100vw - 24px)`。
- 悬浮入口按钮：`right: 26px`、`bottom: 26px`，与右、下边线等距，尺寸 44px。

- 消息区：
  - 用户消息靠右，助手消息靠左。
  - 工具调用折叠为「思考过程」列表，显示工具中文名和状态。
  - 错误以红色文本展示，不伪装成成功。

- 提案卡：显示目标节点、输出方式（新建节点并连线 / 写回版本）、模型、数量、提示词、过期时间，提供「确认生成」「取消」。

  - 附件缩略图、`@` 引用素材、模型选择、权限模式、技能选择。
  - 模型浮窗顶部为「文本 / 图片 / 视频 / 音频」四个 tab，一次只显示一类模型；有已选模型的 tab 显示状态圆点。
  - 发送按钮在生成中变为停止按钮。
  - `Enter` 发送，`Shift+Enter` 换行，`Esc` 关闭菜单。
- 回合结束：有修改时显示「撤销这一轮」，同时回退画布、时间线、场景和拉片快照。

## 15. 剪辑室

剪辑室由画布上的剪辑室节点打开，是全屏浮层。

### 15.1 布局

```text
┌──────────────────────────────────────────────────────────┐
│ 返回  剪辑室 · 项目名       已保存  时长  画幅  帧率  关闭 │
├──────────┬──────────────────────────────┬────────────────┤
│ 素材池   │ 预览播放器                    │ 检查器         │
│          │                              │                │
├──────────┴──────────────────────────────┴────────────────┤
│ 时间线：轨道头 + 标尺 + 片段 + 播放头 + 缩放               │
└──────────────────────────────────────────────────────────┘
```

- 顶栏：返回画布、名称、保存状态、总时长、画幅选择、帧率。
- 左侧：素材池，可拖入时间线。
- 中间：预览播放器，播放头与时间线联动。
- 右侧：检查器，分「属性 / 画面 / 音频」。
- 底部：多轨时间线，支持水平滚动和缩放。

### 15.2 时间线

- 轨道类型：视频、音频、字幕。
- 片段类型：视频、图片、音频、文本。
- 支持选择、多选、拖拽、吸附、裁剪、切分、删除、复制。
- 右键菜单：切分、删除、分离音频、复制属性。
- 播放头、标记、转场、关键帧在时间线上可视化。
- 锁定/静音/隐藏轨道有明确状态。

### 15.3 检查器

- 属性页：名称、时间、速度、音量、静音、透明度、淡入淡出、转场。
- 画面页：位置、缩放、旋转、裁剪、滤镜、关键帧。
- 音频页：音量、淡入淡出、音频效果。
- 未选中片段时显示时间线信息：画幅、分辨率、帧率、片段数、轨道数、标记数、自动粗剪入口。
- 自动粗剪：删静音、按镜头切分、节拍标记、节拍切分，执行前弹确认卡。

### 15.4 导出

- 导出成片前显示编码、分辨率、时长和预计耗时。
- 导出进度显示在顶栏或状态区。
- 完成后写回画布剪辑室节点的输出，并在画布上生成/更新成片节点。

## 16. 导演台

导演台由画布上的导演台节点打开，是全屏 3D 浮层。

### 16.1 布局

- 顶栏：返回、场景名、保存状态、导演视角/机位视角切换、截图、白模预演导出、关闭。
- 中心：three.js 视口，支持旋转、平移、缩放、transform gizmo。
- 右侧：检查器，按对象 / 机位 / 镜头切换。
- 底部：镜头时间线，显示镜头、机位关键帧和动作轨。
- 左侧或浮动面板：添加人物、立方体、球体、平面、群众、本地 glTF。

### 16.2 对象与机位

- 对象：位置、旋转、缩放、姿势、颜色、可见性。
- 机位：名称、位置、注视点、FOV、画幅。
- 镜头：绑定机位、时长、画幅、机位关键帧。
- 关键帧：时间、位置、目标、FOV、缓动；时间线可拖动。
- 背景：纯色、全景图、模型。

### 16.3 白模预演

- 选择一个镜头后点击「导出白模预演」。
- 选择 720p / 1080p、24 / 30fps。
- 导出进度显示帧数。
- 完成后在画布导演台节点右侧创建视频节点并连线。

### 16.4 Agent 行为

- Agent 写场景前自动打开导演台。
- 镜头、机位、背景、对象属性修改后立即落盘。
- 同一轮修改只压一条场景撤销记录。

## 17. 逐帧拉片

### 17.1 入口

- 视频节点工具栏「逐帧拉片」或右键菜单。
- 点击后创建拉片节点，位置在源视频下方并自动连线。
- 不要求打开拉片室。

### 17.2 拉片节点卡片

- 标题：`源视频名 · 拉片`。
- 摘要：`N 个分镜 / N 帧 / 时长`。
- 配置：
  - 分镜精度：自动分镜 / 0.5 / 1 / 2 / 5 秒。
  - AI 描述：自动选择 / 不分析 / 指定视觉文本模型。
  - 输出：分镜组、分镜表、动态切片、BGM。
- 操作：开始拉片、取消、重新拉片、查看分镜表。
- 状态：queued / running / done / error，显示进度和错误。

### 17.3 输出

- 分镜组：每个镜头一张代表帧，按网格排列。
- 分镜表：文本节点，Markdown 表格，包含镜号、时间、景别、机位、运镜、光线、画面、提示词、人声、音乐。
- 动态切片：按镜头截取的视频片段（可选）。
- BGM：整条音轨（可选）。

### 17.4 分镜表浮层

- 只读表格，支持横向滚动。
- 每镜可复制提示词，整表可复制。
- 顶部操作：导出 Markdown、高级编辑、关闭。
- 高级编辑打开原拉片室浮层，不再是主入口。

### 17.5 拉片室（高级编辑）

- 播放器 + 帧时间轴 + 右侧笔记/结构/情绪。
- 段落编辑、字幕列表、AI 分析导入。
- 仅从分镜表「高级编辑」进入。

## 18. 节点工具栏与 Agent 操作

### 18.1 工具栏

- 一级按钮最多 6 个，超出进入「更多」。
- 菜单按「生成 / 编辑 / 视频」分组。
- 「更多」中带子项的操作，鼠标悬浮即在菜单右侧弹出二级浮窗，无需点击；点击仍可作为键盘/触屏兜底。
- 二级浮窗用固定定位渲染在菜单外，避免被菜单滚动区裁剪；靠近视口边缘时自动避让。
- 操作不可用时置灰，title 或点击提示原因。
- 菜单宽度 180–240px，右侧子菜单向上/向左避让。
- 底部工具栏可自定义常用操作。

### 18.2 操作分类

- 切分：宫格切分。
- 裁剪：裁剪、画面裁切。
- 视频：片段截取、分离音视频、抽帧、逐帧拉片。
- 生成：九宫格、角色四视图、画面推演、多角度、720 全景、扩图。
- 图像编辑：抠图、重绘、擦除、元素编辑、图层分离、去字幕。
- 视频编辑：片段重拍、元素替换、主体消除、智能抠像、智能续写。
- 本地处理：深度动作捕捉。
- 输出目标：生成型、裁剪/截取/去字幕和音频派生操作新建节点并连线；光影校正、打光、人像、重绘、擦除、元素编辑写回版本栈。详见 `node-output-target-plan.md`。

### 18.3 Agent 映射

- `canvas_node_operations` 返回同一套操作的 ID、菜单、参数、`agentExecutable` 和 `generationProposable`。
- 17 个操作由 `canvas_node_operation` 直接执行。
- 8 个模型类操作走 `generation_propose`，自动复用操作提示词。
- 3 个蒙版操作（重绘 / 擦除 / 元素编辑）仍需界面涂抹。
- 高风险操作显示确认卡；同一轮操作合并为一条撤销记录。

## 19. 公共组件

基础组件位于 `src/renderer/src/components/ui/`：

| 组件 | 用途 |
|---|---|
| `Button` / `IconButton` | 主按钮、次按钮、图标按钮 |
| `Input` / `Textarea` | 表单输入 |
| `Select` | 自定义下拉选择 |
| `Switch` | 开关 |
| `Field` / `SettingRow` | 表单字段与设置行布局 |
| `Dialog` | 模态对话框、焦点圈定与 Escape 关闭 |
| `Menu` / `MenuItem` / `MenuSeparator` | 固定定位浮动菜单 |
| `Toast` | 页面底部状态提示 |

规则：

- 新代码只能从 `components/ui` 导入这些组件，不再手写同类按钮、开关或设置行。
- 组件使用 Tailwind 语义类（`bg-surface`、`text-fg`、`border-border`、`bg-accent` 等），不硬编码色值。
- 旧页面按「设置页 → 资产库 → 剪辑室 → 画布」逐步迁移。
- 当前设置页已迁移 `Switch`、`SettingRow`、`Input`、`Select`；确认弹窗已迁移 `Dialog` 和 `Button`；全局提示已迁移 `Toast`。
- 资产库的命名/模板、移动/合成/标签弹窗已迁移 `Dialog`、`Field`、`Input`、`Textarea`、`Select`；工具栏、底部操作、`AssetGrid` 和 `FolderTree` 图标按钮已迁移 `Button`、`IconButton`。
- 剪辑室顶部栏/时间线工具栏、检查器字幕与操作按钮已迁移 `Button` / `IconButton` / `Input` / `Textarea` / `Select`；关键帧的紧凑数字输入和两个紧凑 select 留待后续。
- 画布节点工具栏的编辑、音频、剪辑室、下载、展开、入库操作已迁移 `Button` / `IconButton`；操作菜单的浮层仍保留自定义定位，后续再迁移到 `Menu`。
- `Menu` 已提供，但节点/工具栏菜单会在后续批次逐步迁移。
