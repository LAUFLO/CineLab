# STUDIO-INSPECTOR-1 · 预览播放、画幅入口、时间线缩略图、属性面板拆分

日期：2026-11-10

## 1. 预览播放闪烁

根因：每画一帧都按播放头给视频 `currentTime` 赋值，播放时不断 seek，解码跟不上就闪。

处理：

- 播放时让 `<video>` 自己解码播放，canvas 只取当前帧；只有偏差超过 0.3 秒才重新同步。
- 暂停/拖动时才 seek，等 `seeked` 后重绘。
- 不在当前时间范围的视频自动暂停，避免后台播放。

实测：播放 3 秒采样 32 次 canvas 中心像素，仅 2 次为黑（起止帧），播放过程稳定。

## 2. 画幅入口固定到顶部栏

- 剪辑室顶部栏的分辨率文本改为画幅下拉，随时可以切换 9:16 / 16:9 / 21:9 / 3:4 / 4:3 / 1:1。
- 不需要先取消选中片段。
- 切换后预览 canvas 立即按新尺寸重绘（实测 9:16 → `canvas 1080×1920`）。

## 3. 时间线黑色块

根因：片段缩略图用多张 `contain` 图片平分宽度，抽帧数量不足时每张被拉宽，两侧露出黑色背景。

处理：所有视频缩略图统一用第一帧按原始比例 `background-size: auto 100%` + `repeat-x` 平铺，不再裁剪、不再出现黑块。

## 4. 属性面板拆分

属性面板从「属性 / 助手」两个 tab 改为四个：

| Tab | 内容 |
|---|---|
| 属性 | 片段基础（名称、起点、时长、速度）、AI 分析、文字/字幕 |
| 画面 | 缩放、X/Y 偏移、旋转、不透明度、混合、滤镜、转场、关键帧 |
| 音频 | 音量、淡入淡出、保持音高、降噪/增强人声/响度、变声、分离音频、自动粗剪 |
| 助手 | 原有 AI 助手 |

## 5. UI 统一

- 速度、滤镜预设、转场类型、变声全部改用项目统一的 `Select` 组件，不再用原生 `<select>`。
- 属性面板输入框统一 28px 高、6px 圆角、`--surface-raised` 背景。
- 属性面板内的 `studio-ghost-btn` 加了边框和底色，与 `btn-secondary` 视觉一致。

## 验证

- `typecheck`、27 文件 / 162 用例、`build` 通过。
- 隔离实例实测：
  - 顶部画幅下拉 6 个选项，切换 9:16 后 canvas 为 1080×1920。
  - 4 个 tab 内容分别为：属性（基础/AI 分析/文字）、画面（画面/滤镜/转场/关键帧）、音频（声音/自动粗剪）。
  - 时间线片段使用 `is-repeat` 平铺，无 `<img>` 黑块。
  - 播放采样无持续黑帧。
