## 0. 结论

CineLab 的 Agent 助手完整版不是单个聊天框，也不是单一剪辑助手，而是贯穿创作全流程的创作操作系统：

> 4 个创作空间 × 6 层能力。

- 4 个空间：画布、剪辑室、拉片室、导演台。
- 6 层能力：感知、工具、编排、协作、治理、生态。
- 完整版功能拆为 11 个域、202 个功能点。
- 决定成败的不是模型强弱，而是工具层、回合事务、权限、上下文、确认、撤销、恢复、评测这 8 项地基。

本文是完整版范围总表，不是 MVP 清单。P0 表示完整版的第一批地基与核心能力，不表示「只做这些就发布」。

## 1. 产品定位与边界

### 1.1 定位

Agent 是 CineLab 的创作搭档，与用户共用同一套项目、画布、时间线、资产和本地能力。它负责理解意图、读取现场、规划步骤、调用工具、产出可检查的结果。

### 1.2 四个空间的职责

| 空间 | Agent 角色 | 主要职责 |
|---|---|---|
| 画布 | 创作助理 / 制片 | 读画布、建节点、连线、写提示词、批量生成、整理画布、角色与场景资产链 |
| 剪辑室 | 剪辑师 / 导演 | 读时间线、粗剪、精剪、字幕、转场、变速、卡点、多版本、导出 |
| 拉片室 | 影片分析师 | 读拉片数据、逐帧分析、结构/情绪曲线、把拉片结论转成分镜或剪辑方案 |
| 导演台 | 摄影指导 | 3D 片场、素模站位、机位、运镜、本地白模预演、截图/视频回画布 |

### 1.3 边界

- 四个空间共享同一套 Agent 运行时，但对话、上下文、工具白名单、撤销域互相隔离。
- 跨空间操作必须通过显式工具并二次确认，不能默认混在一起。
- 所有写操作必须可撤销、可审计、可定位。
- 付费生成必须先提案、再确认、后提交。
- Agent 只能调用白名单工具，不执行任意代码。
- 只操作当前项目与允许的全局资产，不读写项目外文件。

### 3.5 E 技能与知识

技能格式兼容 `SKILL.md`：frontmatter 提供 `name`、`description`、`version`、`disableModelInvocation`，正文提供方法、步骤、约束，`references/` 提供按需读取的参考资料，`assets/` 提供模板和示例。

技能来源分三级，优先级为项目 > 全局 > 内置：

```
<app>/resources/skills/           # 内置技能，只读
<userData>/skills/                # 全局用户技能，跨项目
<project>/.cinelab/skills/        # 项目技能，随项目走
```

技能是方法论，不是权限。技能不能注册工具、不能扩大工具白名单、不能修改系统提示、不能绕过权限 scope。技能脚本必须用户确认、受限运行、可审计。

## 4. 典型用户旅程

### 4.1 从灵感到短片

1. 用户描述目标：题材、时长、画幅、风格。
2. Agent 问清关键信息，生成故事梗概、角色、场景、道具、分镜表。
3. 在画布上创建角色三视图、场景图、分镜组。
4. 为每个镜头创建首帧图和视频节点，建立连线。
5. 生成前给出生成单：镜头、模型、参数、费用。
6. 用户确认后批量生成。
7. 生成完成后自动检查结果，失败镜头重试。
8. 按分镜顺序送入剪辑室，生成时间线。
9. 自动字幕、配乐、转场、卡点。
10. 给出 2-3 个剪辑方案供选择。
11. 导出成片和可编辑工程。

### 4.2 已有素材快速粗剪

1. 用户把素材拖进剪辑室。
2. 说「删掉所有静音，按镜头切开，跟着这首音乐卡点」。
3. Agent 分析静音/镜头/节拍，生成方案。
4. 用户预览影响，确认应用。
5. 一条撤销可回退。
6. Agent 自动加字幕、转场、片头片尾。

### 4.3 拉片驱动创作

1. 用户打开参考片，进入拉片室。
2. Agent 读帧、段落、结构树、情绪曲线。
3. 用户问「这场戏为什么紧张」。
4. Agent 分析镜头长度、景别、剪辑节奏、音乐。
5. 用户说「按这个结构做一个 30 秒版本」。
6. Agent 生成分镜表、画布节点、剪辑方案。

### 4.4 角色一致性长片

1. 用户上传角色设定图。
2. Agent 建立角色卡、服装变体、表情库。
3. 每个镜头生成时自动注入角色参考。
4. Agent 检查每个镜头角色一致性，发现偏差提出重生成。
5. 全片保持一致。

### 4.5 导演台预演

1. 用户描述场景和镜头，或手动搭好场景、摆人物素模。
2. Agent 根据剧本/分镜设置站位、机位、焦段、运镜。
3. 低清渲染本地白模预演，用户播放检查构图、走位和运镜。
4. 用户调整，Agent 继续修改机位、动作路径或运镜关键帧。
5. 导出白模预演视频回画布，作为正式视频生成的参考视频。
6. 截图作为首帧/尾帧参考，正式生成对应镜头。
7. 正式成片进入剪辑室。

## 8. 验收标准

### 8.1 地基

- 工具注册表能列出全部工具及其权限、scope、参数 schema。
- 画布写操作经过 `CanvasCommand`，可预览、可批量、可审计。
- 一轮 Agent 操作只产生一条撤销记录，Ctrl+Z 可整体恢复。
- 写操作带 revision/幂等键，重复提交不产生重复结果。
- 权限 scope 由主进程构造，伪造 canvasId/assetId 被拒绝。
- 未配置模型时有明确引导，不阻塞 UI。
- 会话重启后可恢复历史与未完成回合。

### 8.2 画布助手

- 「建一个角色三视图并连到分镜组」能正确建节点、连线、分组。
- 「把选中节点的提示词改成夜景」只改目标节点，不影响其他节点。
- 「整理这张画布」能按拓扑排列并聚焦。
- 生成前出现生成单，未确认不产生任何生成任务。
- 生成完成后能检查结果并报告失败节点。
- 取消、失败、断网都有可读提示，不修改文档。

### 8.3 剪辑助手

- 「删掉所有静音」生成正确方案，一条撤销恢复。
- 「按镜头切开」切点准确，变速片段位置正确。
- 「跟着音乐卡点」marker/切分/转场三种模式可用。
- 字幕、转场、变速、关键帧操作可组合执行。
- 用户取消不修改时间线。
- 渲染导出可取消、无残留。

### 8.4 编排与技能

- 计划最多 12 步，同一时间一个进行中，用户可见。
- 不需要确认的步骤可自动继续，遇到确认点停下。
- 失败/中断后可从未完成步骤继续，不重复已完成步骤。
- 用户可以在设置中新建技能，填写 name、description、正文，保存后出现在技能目录。
- 可以导入文件夹/ZIP，预览 frontmatter 和文件列表，确认后安装到全局或项目。
- 项目技能 > 全局技能 > 内置技能，同名覆盖有提示。
- `/skill:name` 或技能菜单可选择；`disableModelInvocation` 的技能模型不能主动读取。
- 技能正文和 references 按需读取，不整包注入。
- 技能跨轮保持，压缩后正文补回。
- 技能更新时提示版本变化，用户确认后切换。
- 路径穿越、绝对路径、符号链接逃逸、超大文件被拒绝。
- 技能不能扩大工具权限；只读模式下技能不能触发写操作。
- 技能脚本（如支持）必须确认、受限目录、超时、审计。

### 8.5 导演台预演

- 新建导演台节点，手动搭景、摆素模、设机位、截图回画布。
- 保存后重开，场景、机位、镜头全部恢复。
- 设置 5 秒镜头和运镜关键帧，导出 720p/24fps 白模 MP4，画面运动与关键帧一致。
- 导出可取消，取消后无残留。
- Agent 按自然语言搭景、摆位、设机位，用户确认后执行，可整体撤销。
- Agent 生成白模预演视频并回画布，视频可作为参考视频连接正式生成节点。
- 白模预演不调用视频模型，不产生模型费用。

## 9. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 中转站 function calling 不稳定 | 工具调用失败 | 原生 tools 优先，结构化 JSON 兜底，失败重试 |
| 画布/时间线上下文膨胀 | 成本高、模型抓不住重点 | digest + 分页 + 历史裁剪 + 压缩 |
| 画布 revision 冲突 | 覆盖用户改动 | expectedRevision + 冲突重读 + 回合撤销 |
| 付费生成误操作 | 用户损失 | 生成单 + 预算 + 幂等 + 失败不重复扣费 |
| 长任务中断 | 结果丢失 | 回合记录 + 任务恢复 + 断点续做 |
| 技能漂移 | 输出不符合方法 | 版本 pin + 跨轮保持 + 压缩后补回 |
| 评测成本 | 无法持续回归 | fake 模式 + 小样本真实回归 |
| 许可证风险 | 法律问题 | 只借鉴设计，不复制 BeefTV 代码；ToonFlow 遵循 MIT |
| 多 Agent 权限扩散 | 安全事故 | 首期不做；后续独立 scope 与审计 |

## 10. 明确不做

- 通用编码 Agent。
- 无限自主、无确认的批量生成。
- 自动删除素材文件。
- 全自动导出并覆盖成片。
- 没有撤销的操作。
- 绕过项目路径的读写。
- 把完整项目 JSON、API Key、绝对路径发送给模型。
- 首期做多租户、账号、计费、云同步。
- 首期做 Agent 市场、插件市场。
- 直接复制 BeefTV 代码（许可证限制）。
